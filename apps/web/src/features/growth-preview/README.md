# 星光收藏：本地视觉原型

2026-11-03，按用户要求先展示效果，确认满意后再考虑集成和发布。

启动：在仓库根目录运行 `pnpm exec vite --config apps/web/vite.config.ts --host 127.0.0.1 --port 5186`，访问 `http://127.0.0.1:5186/growth-preview.html`。

- 单独 HTML 入口，未接入当前应用入口、路由、认证或数据库；正常课堂/比赛构建不会自动引入此预览入口。
- 当前版本按用户最新要求取消 0/5/10 自动阶段示意，改为 7 款边框与 5 款星环/主题外观的预设目录，所有预设 `locked: true`、`unlockCondition: null`。解锁条件由用户后续决定，不预设任何次数门槛。
- 边框：月辉银饰、日冕鎏金、蓝宝星穹、翡翠秘境、琉璃虹窗、繁花绘梦、立冬·霜华初绽。星环/外观：银月丝轨、鎏金冠冕、宝石星链、虹彩珐琅、水母·星海巡游。不同款式使用实际不同的花丝、月桂、宝石、彩窗、花饰、星刻与珠链图形，并非仅换色。
- 翡翠、琉璃、繁花三款新增大冠饰、宝石垂链、彩窗扇片/边条和更丰富的花束藤蔓。立冬使用霜晶窗棂、青灰冬枝、暖金叶片和“立冬”文字牌。立冬/水母仅标注拟关联对应设计作业，尚未绑定任何实际任务或自动授予。
- 每款边框配套独立浮饰：月牙风铃、日轮金铃、蓝晶吊坠、翡翠叶蝶、琉璃流苏、彩绘花蝶、霜柿小灯。试戴边框时自动配套，可单独隐藏。
- 本地试戴中直接拖动浮饰定位，支持鼠标与触屏、方向键微调、Shift 大步微调、Home 复位、Escape 取消当前拖动。位置以场景归一化坐标记录；拖动时暂停自身动画、松开后恢复；画面边缘预留运动余量，避免完整浮饰被裁切。拖动过程仅更新浮饰组件，松手才提交到本页状态，不触发后端写入。
- 配套浮饰有“静止/轻柔/明显”三档整体浮动幅度；“静止”同时停止其内部翅膀/微光等运动。每款在本次页面会话内分别记住位置与幅度，切换款式不丢调整，刷新不持久化。复位位置只影响当前浮饰，保留幅度、背景和作品位置。
- 初次打开不装备边框/星环，对应开关准确显示未勾选。未选款式时勾选开关会试戴默认鎏金款，关闭只隐藏、再打开保留款式。所有预设均可“试戴”，试戴后仍显示“已锁定”且不改变目录数据。“结束试戴”或刷新清除当前试戴。没有本地解锁绕过或伪造奖励接口。
- 环绕卫星、默认星灯及微光沿用前一版效果示意，与实际奖励授予无关。三组装饰配色同步调整当前试戴边框、星环、浮饰的线条/光效及卫星、水母色调；主题宝石、花瓣、柿子等图案保留各自辨识色。未试戴星环时点击配色会临时试戴默认星环，使变化清楚可见。“原配色”恢复预设自身的材质；目录缩略图始终使用原始设计。所有配色操作不染色或更换学生原画。
- 水母外观为 3 只 SVG 小水母沿 CSS 轨道环绕，前后两层绘制共享同周期/相位，交替显隐，与星球主体形成遮挡。触须有轻微摆动；每只 4 个光点，可随“微光粒子”关闭。前后层保留绘制副本，最多同时显示 3 只水母/12 个附属微光。预设缩略图全部静态；页面隐藏、暂停或减少动态设置时停止动画。没有导入实验室 Three/WebGL、水母点云或辉光后处理；未承诺未经低配实机测试的帧率。
- 所有新增装饰为可编辑 SVG 与 CSS。内外原画直接复用现有项目图片，未修改图片文件；作业元素为虚拟点击示意，不关联真实作品记录。
- 高饱和/浅色背景切换及本地背景上传。上传只用浏览器 Blob URL 预览，离开页面释放，不发送到服务器。
- 动画支持系统减少动态效果；粒子与边框不拦截作品按钮。
- 未实现真实计数、永久解锁、跨设备/刷新保存或完整课堂接入。自由拖动仅在预览会话中保留。独立测试部署不改变课堂服务、比赛版或 EXE。

验证：类型检查、此目录 ESLint、真实 Chromium 浏览器操作。当前主题/浮饰结果及截图位于 `outputs/growth-themes/`；`work/growth-themes-check.py` 实际试戴全部 7 组边框/浮饰、12 项保持锁定，验证冬季主题、红/浅/复杂背景、浮饰换边及隐藏、水母实际运动和粒子关闭、目录静态、减少动态与暂停、作品点击、移动端无溢出、无 API 请求/Canvas/WebGL。`outputs/growth-presets/` 和 `outputs/growth-preview/` 为之前两轮历史证据。

拖动与幅度验证：`work/growth-drag-check.py`、`outputs/growth-drag/checks.json`。实际鼠标拖动、真实触屏事件、拖动暂停/结束恢复、点击不跳位、三档幅度、切换款式记住各自参数、方向键、Escape 取消、复位位置、出界限制、窄屏调整、减少动态、作品点击通过；没有 API 请求。主题回归脚本已改为新的浮饰定位方式。

独立云端测试部署：`pnpm growth:preview build` / `pnpm growth:preview deploy`。专用 Vite 配置只构建此 HTML 入口，所有图片及脚本使用 `/growth-preview/` 前缀；独立静态 Worker 没有认证、数据库、上传或课堂服务绑定。域名网关仅将该前缀转发至预览，其他路由保留。部署与实际版本记录参见 `docs/75-isolated-growth-preview.md`。

可复现浏览器检查：`tests/growth-preview-themes-browser.py`、`tests/growth-preview-drag-browser.py`；通过环境变量 `GROWTH_PREVIEW_URL` 指定本地/云端入口，`GROWTH_OUTPUT_DIR` 指定证据目录，`GROWTH_PREVIEW_PROXY` 可选配置代理。它们只操作静态预览，不调用课堂 API。

开关/配色回归：`tests/growth-preview-controls-browser.py` 覆盖空选择状态、开关默认试戴与保留、前弧/球体/后弧层级、开启/关闭实际截图差异、三组配色实际画面像素差异、边框与浮饰同步、原配色恢复、水母变色、原图不变与锁定状态。证据 `outputs/growth-controls/`。
