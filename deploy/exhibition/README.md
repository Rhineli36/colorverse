# 比赛展示部署与后续课堂服务器

目标先满足智慧教学比赛的公开查阅，再在 2026 年 11 月 3 日开课前完善真实课堂服务。

## 当前已经准备好的展示包

运行 `pnpm build:competition` 生成 `work/competition-site/`。这是独立静态网站，5 个作业风格案例、25 件原作压缩预览、5 个默认星球、教师统计快照和点评建议都在站点内。浏览无需登录，也无需连接 Supabase、Cloudflare API 或数据库。点赞是本页演示，不写入真实课堂。生成图不替代原作，点评和建议分不计正式成绩。

将该目录的**内容**上传到静态网站根目录即可。必须通过 HTTP/HTTPS 打开，不能双击本地 index.html。子目录地址需以 `/` 结尾；例如 `/exhibition/`。演示包不需要任何 .env 文件、数据库密码、后端 Secret key、学生密码或原始 PPTX。

## 推荐先按月使用腾讯云香港轻量应用服务器

核对时间：2026-10-14。官方香港 Linux 锐驰型套餐：2 核 2 GB、40 GB SSD、200 Mbps 峰值带宽、无限流量，标价 **55 元/月**。对于静态比赛展示，先按月用这个规格；域名另计，实际可购库存、优惠和续费以订单为准，不开自动续费。暂不额外购买数据库、对象存储或 CDN。

[官方基础套餐定价](https://cloud.tencent.com/document/product/1207/73452)。另有 38 元/月的入门型，但官方特别提示它无法保障内地至香港的跨境公网质量，不作为比赛首选。香港跨境访问仍可能产生延迟和丢包，200 Mbps 也只是峰值上限；购买后必须在学校网络及手机网络关掉代理实际测试。[官方地域与网络说明](https://cloud.tencent.com/document/product/1207/50103)。内地部署和绑定网站域名需要 ICP 备案，香港部署不需要内地 ICP 备案；后续若需更稳定的内地课堂访问，应比较学校现有服务器/已备案域名或办理内地部署。[备案地域要求](https://cloud.tencent.com/document/product/243/19630)。

购买和域名注册尚未执行。现有 workers.dev 和 GitHub Pages 镜像并不能解决国内可达性问题，不能视为已经完成评委网络验证。

## 静态部署步骤

1. 新建 Linux Ubuntu 24.04 的香港轻量实例；放通 80 和 443，仅限自己的 IP 使用 SSH 22。
2. 服务器安装 Nginx；把展示目录内容放到 `/var/www/colorverse-exhibition/`，Nginx 工作账号仅需读取。
3. 使用本目录 `nginx.conf`，先用公网 IP 的 HTTP 地址检查图片、作品弹窗、教师快照、手机布局。只读展示没有登录口，不发送密码。
4. 购买域名后设置 A 记录指向公网 IP，并配置可信 HTTPS 证书；正式比赛只发 HTTPS 链接。HTTPS 的证书域名必须匹配，不能把 localhost 配置原样用于公网。
5. 从校园宽带、不同手机运营商实测；刷新打开五个案例、25 件作品和点评；如比赛现场网络不好，准备同一展示包的本机 HTTP 备用演示。

## 后续真实课堂迁移

`deploy/server/` 准备了 Node 生产适配器、Docker Compose 和 Caddy HTTPS 配置，复用真实 Supabase 登录、受限数据库角色和私有 Storage；不是本地 fake-auth 开发服务。浏览器登录可通过同源受限接口转接，避开浏览器直接连境外 Auth 的依赖；服务端本身仍需可靠连通 Supabase。

迁移必须配置独立受限 reader/writer 数据库连接和严格 CA 验证；IPv4 主机优先评估 Supabase session pooler，不能在不支持 IPv6 的主机直接使用 IPv6-only 的数据库主机。检查池化角色用户名和证书链后再上线。适配器已有真实 HTTP 单元验证；本机没有 Docker，**尚未完成真实 Linux/Docker 部署测试**。真实课堂迁移需追加多设备登录、上传、重试、权限隔离、备份恢复和教师统计验收。
