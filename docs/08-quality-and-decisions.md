# 08 · 验证策略、架构决策与风险

## 1. 验收矩阵（待开发执行）

| 编号 | 内容 | 方法与通过条件 |
| --- | --- | --- |
| T01 | 宇宙交互 | 浏览器自动化：拖动/缩放/悬停/选择/进出/返回状态；搜索名称/颜色/情绪；键盘可选中 |
| T02 | 编辑参数、原图、撤销 | 领域往返及浏览器：六项调色保存重载值一致；拖动一次一个历史；重置可撤销；原始字节 hash 不变；透明边缘截图复核 |
| T03 | 场景与档案 | 多层 z-order、图层绑定热点、缩放后命中一致；弹窗显示正确档案；缺失/无权引用有占位不泄露内容 |
| T04 | ZIP 媒体还原 | 电脑 A 导出，电脑 B 新浏览器配置导入；无原本机缓存/外网也可读取所有打包素材；原图与音频 SHA 一致；场景截图允许合理渲染容差 |
| T05 | 版本兼容 | 每个支持版本 fixture 迁移并往返；未来主版本拒绝写回；迁移失败原包保留；原图不变 |
| T06 | 错误与不可信包 | 缺图、hash/MIME 错、重复 ID、路径穿越、大小写冲突、未知能力、炸弹/超像素/超额度、超深 JSON 均可解释失败，不污染正式库 |
| T07 | 保存失败 | 注入配额不足、事务失败、刷新中断；恢复上次完整版本；临时素材可清理，原图不先删除 |
| T08 | 多窗口与撤销 | 两标签页编辑触发 revision 冲突；连续拖动、删除引用、撤销重做、重新打开后文档一致；历史内存有界 |
| T09 | 教师宇宙管理 | 导入、重复导入、复制冲突、隐藏/显示/移除；完整宇宙/分批集合恢复布局、隐藏状态与全部资产；缺包不切换 |
| T10 | 模拟生长 | 同触发并发执行仅一事件/一组图层；事务中断无半成品；拒绝不生长；刷新/ZIP重载保留；撤销不覆盖人工修改 |
| T11 | JSON 资源不全 | 显示缺失列表、允许隔离只读、禁止完整发布；补资源后可恢复 |
| T12 | 规模与渲染 | 5/40/100/300颗、不同画质/大量热点/高像素图片；依下方预算并记录原始数据 |
| T13 | 可访问性与降级 | DOM 列表/键盘/焦点返回、中文长文本、减少运动；GPU失效、上下文丢失时可只读且文档不丢失 |
| T14 | P2 提交事务 | 截止边界/服务器时间、迟交、退回重交、并发提交/评阅、唯一版本、自动入档；旧评语准确绑定旧版 |
| T15 | P2 权限与发布 | 跨用户/跨班级资源 ID 与导出攻击；原图私有、签名过期；公开响应/包/缓存无学号、评语、私人来源；撤回后不可新取 |
| T16 | P3 可靠性与预算 | 模型无效JSON/未知预设/越界、429/超时/断网、Worker重启、租约到期、幂等竞争、教师审核失效、月上限熔断 |
| T17 | 备份恢复 | 数据库+对象恢复到新环境，核对原图、历史、热点、公开引用；确认 RPO/RTO并记录耗时 |

单元测试覆盖领域不变量；Repository 共用契约测试套件验证内存/IndexedDB/HTTP；集成测试覆盖事务与媒体闭包；浏览器测试覆盖学生实际路径。不把代码编译通过当成性能、色彩或跨机还原验收。

## 2. 性能预算（设计目标，尚无实测）

测试机器建议 Intel i5 第8代同级、8GB RAM、集成显卡、1920×1080；Chrome/Edge 稳定版，记录精确版本、电源模式和硬件加速状态。每种用例冷启动和热启动各测至少5次，报告中位数/p95及失败，不只挑最快一次。

| 场景 | 预算与策略 |
| --- | --- |
| 首次 40 颗总览 | 10 Mbps/100ms RTT 模拟下可交互目标≤5秒；首屏资源≤4MB压缩传输，不拉原图或内部场景 |
| 300 颗总览 | 聚合/剔除后持续拖动的 p95帧时≤33ms（约30fps），目标60fps；只渲染可见缩略图 |
| Studio 典型场景 | 20张图层、10热点、2种效果，连续拖动和调色反馈≤100ms，p95帧时≤33ms |
| 近景图片 | display≤2048长边，DPR上限1.5默认；高质量2按设备启用 |
| 粒子 | 默认同屏≤1000、低质量≤300；对所有预设合计预算，不能每图层各无限增长 |
| 缓存 | 目标解码纹理预算≤256MiB、可测JS heap≤200MiB；单2048² RGBA约16MiB，另需考虑GPU副本/滤镜buffer |
| ZIP | 50MiB代表包导入目标≤15秒（必须实测），显示进度/取消；100MiB上限不是15秒保证 |
| 背景标签页 | 暂停动画/减少ticker；切场景后释放纹理、临时URL、事件监听器 |

JS heap 不等于浏览器总进程内存或显存。300×2048² 纹理约4.8GiB，仅这一项就不可接受；必须用缩略图/懒加载。内存实测采用 DevTools/系统进程观测并解释测量范围，不能报告不存在的精确GPU读数。

## 3. 架构决策记录

| ADR | 决策 | 原因 / 重新评估条件 |
| --- | --- | --- |
| 001 | 二维原创图层为核心，Pixi WebGL；不用完整三维引擎 | 突出学生原创；只有真实球面展示成为硬需求才加Three适配 |
| 002 | 本地优先，P2模块化后端，暂不微服务 | 小班规模；独立性能/团队边界成熟后再拆 |
| 003 | 协议与renderer独立，参数可序列化 | 换存储/模型无需重写视觉；禁止导出运行时对象 |
| 004 | 原图不可变，派生图与滤镜分离 | 可靠还原、色彩教学可回溯；原图清理必须检查历史引用 |
| 005 | 私密文档/提交版本/公开快照分开 | 防止公开展览泄露评语和未来更新；发布采用资源白名单 |
| 006 | ZIP是便携备份，JSON是配置交换 | 浏览器存储可丢失；大包采取分批/服务端流式 |
| 007 | 课程关系规范化，视觉文档JSONB | 兼顾授权约束与图层演进；热点投影不可独立写 |
| 008 | AI仅建议受限预设，学生确认后原子应用 | 成本和可控性；无须每次生图；模型停机仍能手动创作 |
| 009 | 版本锁+提交幂等，暂不自动多端协作 | 减少隐性覆盖；将来有多人实时编辑才评估CRDT |
| 010 | 日期以UTC存储、课程时区解释 | 迟交判定由服务器执行，不信客户端时间 |

## 4. 优先风险与处理门槛

| 优先级 | 风险 | 措施 / 责任阶段 |
| --- | --- | --- |
| P0 | ZIP炸弹、超像素图和峰值内存 | 实際解压字节限额、可中止、先检查头；P0未证明限额有效就不开放任意包导入 |
| P0 | 原图丢失/浏览器清理/错误覆盖 | hash不变、本地事务、备份导出、迁移留原件；P1上线门槛 |
| P0 | P2权限或发布泄露 | 服务端班级授权、安全发布DTO/媒体白名单、跨班测试；P2门槛 |
| P1 | 调色和透明边缘效果不一致 | 同一渲染路径与色彩规则、固定样本视觉回归；P0/P1 |
| P1 | 普通电脑掉帧 | 实测LOD、全局粒子/纹理预算，低质量档；P1b |
| P1 | 成长事件重复/撤销覆盖手改 | 唯一触发键、事务、版本锁、精确补偿；P1模拟就验证 |
| P1 | 作品归属和素材版权不明 | 来源字段和发布选择、演示素材许可清单；P1发布前 |
| P1 | AI超支/供应商差异 | 能力探测、调用预算、局部关闭、Mock回退；P3 |
| P2 | 文档协议和实现漂移 | contracts单一来源、生成Schema、CI fixture；每版发布检查 |
| P2 | 学期留存和备份增长 | 确认期限、可复算容量、完整恢复演练；P2 |

“P0/P1/P2”在本表优先级栏表示严重程度，不是开发阶段；责任阶段另列在措施中。

## 5. 本轮验证边界

本轮只对文档本身进行相对链接、JSON语法、成长Schema与示例、数值范围和成本算术检查。未创建应用，没有运行端到端、ZIP导入、数据库迁移或性能基准。后续任何“已实现/已验证”的报告必须引用真实测试结果，不能继承本文件的目标作为事实。
