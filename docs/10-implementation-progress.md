## 具体化设计与限制

- 使用 pnpm workspaces 管理原计划的模块目录；只创建实际前端与包，未创建云端空壳。依赖版本由锁文件固定。
- ZIP 导出继续使用 JSZip；导入使用 fflate 增量解压并在 Worker 中检查实际输出额度，回应 04 的限制要求。
- SceneDocument 增加明确 tombstones 数组，记录已撤销成长图层；单一 Zod 源生成结构 JSON Schema，跨引用/状态由领域层检查。
- Hotspot 的形状判别具体化为 geometry.type。该选择已回写04；保留原设计的场景坐标/图层局部坐标语义。
- 6 颗演示星球是仓库脚本生成的合成画面，不是学生原创。10 幅格式/尺寸测试图与 WAV 也是合成数据。真实学生素材、目标机房设备尚未提供，P0 真实素材/设备门槛仍待验证。
- 正式账号、云端课程服务、真实模型仍属于后续阶段；课程后端本机闭环已完成，见22。
- 完整 P1b（大宇宙分批备份、300 颗实机性能、可选球体完善、音频全格式、完整无 GPU 降级等）未宣布完成。

## 已发现并修复的问题

1. 上传替换主体后选择状态引用了临时新ID：改为选中实际保留的主体图层ID，浏览器回归通过。
2. 文本框/选择框的嵌套label使可访问名称混入正文或选项：统一控件显式设置aria-label，热点图片弹窗回归通过。
3. 保存完成时可能覆盖仍在编辑的新状态：markSaved只更新revision，并保持新的编辑dirty，模块测试覆盖。
4. 场景反复编辑可能保留渐变纹理/滤镜：加入切换时清理和dispose清理；浏览器反复切换无运行时错误。完整内存长期观测仍待P1b。
5. 相机平移/缩放曾触发总览重载：拆分镜头与场景加载路径，新增浏览器检查确认场景generation不变，轨迹连续运行。
6. 首次挂载/返回期间过时的异步相机更新可能覆盖新视角：取消过期回调，并清除相同相机值对应的旧过渡目标；返回和重置全景回归通过。
