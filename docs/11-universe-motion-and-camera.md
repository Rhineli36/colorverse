# 11 · 宇宙轨迹与镜头

日期：2026-10-09。按新增需求扩展既有 React / PixiJS / domain 架构，不改作品、素材和成长事件的结构。

后续同日增量：空间主视觉与布局权限进一步升级，见 [12-space-exploration-and-layout.md](12-space-exploration-and-layout.md)；最新镜头上限和测试结果以本文件更新及10/12为准。

## 用户体验

- 默认进入宇宙全景，界面文字缩为上方引导，将中央画面留给整体宇宙。
- 每颗星球有独立、轻缓的椭圆轨迹，周期90–190秒，方向、倾角、半径和起始相位各不相同。轨迹线默认隐藏，可通过“显示运行轨迹”单独开启；装饰星环跟随主体。
- “宇宙全景”根据可见星球、全部运行范围和主体占位自动取景；筛选和窗口大小变化后重新适配。
- “局部探索”将当前作品所在区域放大到0.85；“聚焦星球”使用0.38，约1.25秒完成95%的过渡并缓慢跟随选中的星球。点击保留周边空间，进一步近看可用局部探索或手动缩放；清晰度与最新验证见[20](20-gentle-focus-and-artwork-resolution.md)。
- 点击画布星球或作品列表先聚焦，再次点击同一颗画布星球进入内部，也可通过卡片的“进入星球内部”按钮进入。返回后保留镜头模式、筛选、选择和暂停状态。
- 手动拖动/缩放进入自由视角，停止跟随；点击全景或重置重新看到整体。
- 可暂停/继续运行。系统设置减少动态效果时，轨迹停止、镜头直接切换，暂停按钮说明系统限制。
- 新建或导入单颗作品时只分配新的分散锚点，保留已有布局；导入完整宇宙的明确位置继续尊重原配置。
- 作品列表支持横向滚动，适配二十多颗星球与窄屏，不将页面撑宽。

## 模块和状态边界

`packages/domain/src/universe.ts` 提供纯计算：planetOrbit、orbitPosition、orbitBounds、overviewCamera、cameraAt、nextPlanetPosition。轨迹由 layout.seed 和 planetId 确定，同一布局重新加载仍有同一条路径。运行时0秒对应持久锚点。

`packages/renderer` 保存运行时间、Pixi节点和镜头过渡。可见标签页按 delta time 前进，隐藏标签页不累积时间；暂停后保留当前位置。宇宙轨迹独立于学生场景里的 float/rotate 动画，不修改外观绘画方向或保存参数。聚焦跟随实际渲染位置，画布选取使用 Pixi 的当前变换。

`SceneCanvas` 的场景加载与镜头、暂停、焦点更新分为独立路径。挂载期间取消过时的异步镜头更新，防止初始尺寸测量或返回场景覆盖最新镜头。拖动/滚轮只更新镜头，不销毁星球节点或重新加载纹理。

`UniverseView` 负责视角按钮和窗口测量；App 保存视角模式、选择与暂停会话。当前运行时间属于渲染器实例，离开总览再返回时重新从稳定的锚点开始，不代表长期天体模拟。布局文件无需新增轨道字段。

镜头沿用1600×900设计坐标，聚焦点 `(px,py)` 的平移为 `((800-px)*zoom,(450-py)*zoom)`。全景范围包含旋转椭圆的极值及主体占位，并保留至少5200×3000的空间背景，预留上方引导和底部工具栏区域。全景最大zoom为0.32，滚轮允许0.04–2.5。

新增位置使用确定性的黄金角候选布局和距离检查，只分配新条目，不对已有作品重新排序/重新排布。当前没有物理碰撞模拟；轨迹可能在空间中交错。

## 已执行验证与边界

7项宇宙模块测试覆盖路径的稳定性/差异性/闭合周期、原布局不变、完整轨迹边界、24颗新增布局和全景取景、隐藏/空筛选、聚焦坐标、鼠标位置缩放、任意区域取景。另有5项布局授权/迁移检查；全部34项模块测试通过。

生产预览的10项浏览器检查覆盖默认远景、实际运动与暂停、点击运行中的星球、局部/聚焦镜头、返回模式与暂停恢复、拖动不重载场景及全景重置、24颗模拟作品取景/搜索/聚焦、系统减少动态效果、移动端控件、运行时错误。24颗验证使用六种系统演示素材的副本与正式布局函数生成的锚点，不是额外创建的真实学生作品；使用独立浏览器上下文。

运行 `python tests/universe_navigation.py`，依赖见 tests/requirements.txt。`COLORVERSE_TEST_URL` 可指向开发或生产预览，`COLORVERSE_BROWSER_CHANNEL` 控制Chrome/Playwright Chromium。输出截图和报告位于 outputs/。

本次不替代原计划的100/300颗LOD、纹理LRU和普通机房设备性能验收。全景缩放下限为0.04，极端远距离的人工布局仍可能超出可完整取景的范围。完整协议与第一阶段未完成项目继续以04、06、08、10为准。
