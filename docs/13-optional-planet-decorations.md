# 13 · 可选装饰与星球进入交互

日期：2026-10-09。沿用 SceneDocument、独立图层、Zod 契约、统一 PixiJS 渲染与本地保存，不改原始绘画文件。

## 操作入口

创作工坊的「✦ 装饰星球」定位到装饰选项。学生可以自由叠加以下图层，每个图层可选择、调参、隐藏、删除、撤销或重做：

| 分组 | 可选项 |
| --- | --- |
| 粒子与气氛 | 星尘、萤火虫、漂浮光点、雨、雪、雾气 |
| 光影 | 外发光、柔光、边缘光、光束、呼吸光效 |
| 光环与卫星 | 星环、光晕、卫星 |

效果颜色、强度、透明度与运动速度统一控制；粒子另有密度。卫星可设为1–3颗，调整轨道半径100–600px、大小4–60px和椭圆压缩比0.15–0.9。速度0停止效果自身运动；主体仍可保留独立的动画。显示/隐藏层、改变景深和位置沿用原有图层工具。

在宇宙画布首次点击星球先聚焦，再次点击同一颗已聚焦星球进入内部空间。卡片提供明确的「进入星球内部」按钮，支持键盘；作品列表仍用于定位与聚焦。内部绘画空间、档案热点、编辑入口继续保留，返回宇宙后恢复视角和暂停状态。拖拽不会被识别为进入操作。

宇宙的细椭圆线是固定在空间中的运行轨迹，默认隐藏，通过「显示运行轨迹」单独查看。它与跟随主体的装饰星环区分，切换不重载场景或重置运动时间。

## 数据协议与兼容

沿用 `kind: effect` 和 `effectVersion: 1.0.0`。新增已注册ID为 `halo`、`rim-light`、`satellite`，继续使用固定参数范围和确定性seed；不加载任意脚本、着色器URL或外部媒体。

EffectParams保留已有 color/intensity/density/opacity/speed/seed，新增可选 orbitRadiusPx/satelliteRadiusPx/satelliteCount/orbitTilt。旧效果不需要补字段，读取时采用有界默认值。卫星数量必须为整数。

Effect source新增可选 `anchorLayerId`。它只允许引用同场景的图片图层，禁止效果之间引用和循环；存在该字段时，效果transform表示相对主体的局部坐标。新建装饰在有图片主体时默认绑定，初始偏移为0、相对缩放为1；右侧显示「相对水平/垂直位置」。内部与非主体图片的绑定同步图片变换；外观主体的装饰引用固定星球框架，重新取景不挪动光环。宇宙整体漂移和拖拽仍同步全部装饰，当前规则见[18](18-fixed-planet-frame-and-image-fit.md)。删除被引用的图片图层时，将装饰转为场景坐标并解除引用，避免悬空引用；隐藏主体时隐藏其绑定装饰。

新ID或跟随引用要求 `requiredCapabilities` 声明 `decorations@1`；现有 `effects@1` 继续保留。旧作品不做自动坐标迁移，未绑定的旧效果仍按原场景坐标解释。不能支持新能力的旧程序应拒绝打开新包，避免静默丢失装饰。ZIP副本导入重映射跟随引用和所有图层ID。

作品JSON、IndexedDB、历史命令和ZIP都保存装饰与参数。渲染时间属于会话，不写入文档；导出或刷新重新开始运动，恢复相同轨道、seed和配置。原始素材hash与字节保持不变。

## 渲染与模块边界

- domain提供装饰分组、图层工厂、局部坐标合成、确定性粒子/卫星位置和总粒子预算。
- contracts校验结构与参数；domain校验跨引用与能力声明。
- Studio的EffectControls提供参数控件，继续通过编辑会话生成历史命令与自动保存。
- renderer/effects负责画面，SceneRenderer统一管理时间、暂停、生命周期和主体变换。没有独立效果ticker或额外动画循环。
- 宇宙在主体缩略图周围实时绘制外观效果；装饰和主体在同一星球容器内，宇宙漂移和拖拽整体生效。按原始图片尺寸换算到512px缩略图坐标，保持相对比例。内部空间效果不显示在宇宙总览。

粒子分别缓慢漂移、闪烁，雨雪按有界区域循环。总览对所有可见作品共享预算，单场景也共享预算：常规最多1000个粒子，低质量渲染配置最多300个；隐藏层不占预算，采用向下取整确保不超限。每层常规上限180、低质量50。卫星每层最多3颗。减少动态效果保持初始静态画面，暂停冻结宇宙、粒子和卫星；隐藏浏览器页不累积时间。重载/销毁场景清除效果更新回调、图形、滤镜与临时纹理。

当前效果为二维装饰；卫星采用椭圆绕行和明暗/远近提示，未宣称具备三维光照、实体球面遮挡、物理碰撞或任意素材自动轮廓识别。自定义绘画可通过相对位置和大小校准装饰。低质量配置是渲染器已有能力，当前界面未提供质量切换。正式机房的100/300颗星球性能验收继续属于P1b。

## 验证

新增8项装饰模块测试覆盖全部预设契约、主体局部坐标、兼容能力、无效引用拒绝、参数边界、卫星闭合/静止、可重复粒子和共享预算。ZIP模块增加原始字节、全部装饰参数及引用重映射往返测试。

浏览器脚本 `tests/decorations_browser.py` 验证可选入口、卫星调参/真实运动/静止、装饰叠加、隐藏删除撤销、保存刷新、宇宙同步与暂停、ZIP隔离恢复、减少动态效果、移动端、两次点击进入内部与档案、主体移动后星环像素位移，以及轨迹默认隐藏和独立切换。最终结果以10号进度文档和 outputs/decorations-test-report.json 为准。
