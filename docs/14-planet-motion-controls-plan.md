# 14 · 星球运动设置与预设轨迹（后续开发）

日期：2026-10-09。状态：需求已确认，尚未实现。延续既有宇宙布局、确定性运动、主体装饰跟随与归属权限架构；本文件不改变当前运行时协议。

## 已确认的功能与范围

学生可以设置自己星球的运动状态：静止、缓慢运动、快速运动，并选择受控的轨迹预设。教师可以控制当前班级宇宙内的全部星球。学生不能设置或移动其他人的星球，作者署名、被选中或导入作品包不会产生控制权。

首版提供预设选择，不开放手绘路径、任意控制点或代码。运动设置控制星球在宇宙中的位置变化；粒子、卫星和其他装饰的自身动画继续由原有装饰参数管理，主体移动时装饰整体跟随。

## 首版交互建议

创作工坊新增「星球移动」面板，提供三种模式；运动状态下出现轨迹预览卡、活动范围和方向。只读查看别人的星球时可看设置，但控件不能修改。教师从宇宙管理面板选择任意星球，使用同一组设置。

| 模式 | 行为 | 建议首版速度范围 |
| --- | --- | --- |
| 静止 | 固定在布局位置，不产生宇宙位移 | 不运行路径时钟 |
| 缓慢 | 轻缓运行，适合默认班级展览 | 每周期90–190秒；沿用现有默认节奏 |
| 快速 | 明显更活跃，仍能点击和观察 | 每周期30–60秒；不开放无限速度 |

| 轨迹预设 | 视觉效果 | 约束 |
| --- | --- | --- |
| 圆形绕行 | 在局部空间中稳定转圈 | 周期闭合、半径受限 |
| 椭圆绕行 | 现有默认轨迹，方向与倾角有差异 | 长短轴受限、周期闭合 |
| 八字漫游 | 在两个小区域间交替运行 | 平滑闭合、不使用随机控制点 |
| 轻柔往返 | 在一个小范围内来回漂移 | 正弦往返，到端点自然减速 |

活动范围只提供「紧凑 / 常规 / 开阔」三档。建议最大单轴振幅240个宇宙逻辑像素，方向为正向/反向；首版不提供任意周期、路径点、轨道中心或无限半径。数值作为实现前的视觉校准起点，不作为已测性能承诺。

配置时可预览并取消，保存沿用编辑反馈和错误恢复。切换模式或轨迹以当前星球位置作为新的布局锚点，设置与锚点一起保存；路径在0秒严格经过该锚点，避免切换时突然跳走。拖拽时暂停正在操作的星球，释放后从新锚点运行。

教师的首版必需能力是修改任意单颗星球；后续可增加批量设为静止/慢速、恢复默认，批量操作应有预览、原子保存和冲突报告。教师在单颗星球上应用的配置可由归属学生继续调整；教师锁定或禁改属于另一个待确认需求，不默认加入。

现有「暂停运行」是本次浏览会话的播放控制，不保存每颗星球的模式。个人暂停、隐藏标签页和系统减少动态效果都只影响当前显示，不改变持久设置，更不授予控制他人星球的权限。

## 数据归属与兼容方案

配置建议放在 `UniverseEntry.motion`，与 position/scale/visible 同属该宇宙的展示布局；不写入原始绘画、场景图层或PlanetRevision。同一作品在不同展览中可以有不同运动设置。

拟议字段如下，属于设计示例，当前Zod尚不接受：

```json
{
  "motion": {
    "version": "1.0.0",
    "mode": "slow",
    "trajectory": "ellipse",
    "range": "regular",
    "direction": "forward"
  },
  "layoutRevision": 0
}
```

mode允许stationary/slow/fast；trajectory允许circle/ellipse/figure-eight/drift；range允许compact/regular/wide；direction允许forward/reverse。静止时保留上一次轨迹选择，方便重新开启。seed仍由宇宙seed和planetId产生，不保存每帧位置或无限轨迹数组。

实现时冻结新的Universe/布局版本与 `motion-presets@1` 必需能力，宇宙备份manifest明确声明；配套读取迁移和生成Schema，不能只向现有strict v1文档塞字段。旧Universe缺少配置时保持现有慢速椭圆、活动范围和相位，不移动旧锚点，不重排已有星球。旧motion计算分支保留，只有用户主动配置后才采用新预设。旧程序遇到新版本/必需能力应明确拒绝，避免悄悄丢掉设置。

完整宇宙备份包含运动配置；单星球ZIP仍包含作品与装饰，不携带某个班级的运动布局或owner身份，导入新的宇宙后使用默认运动设置。首次加入新星球、隐藏、显示和副本导入均须明确采用默认值且不覆盖其他条目。

## 权限与保存边界

| 操作 | 归属学生 | 其他学生 | 当前班级教师 | 访客 |
| --- | --- | --- | --- | --- |
| 设置模式、轨迹、活动范围与方向 | 可以 | 禁止 | 可以 | 禁止 |
| 移动布局锚点 | 可以 | 禁止 | 可以 | 禁止 |
| 查看公开展示、控制自己的浏览镜头/暂停播放 | 可以 | 可以 | 可以 | 按展览访问策略 |

P1本地实现从独立ownership读取归属，沿用LayoutActor和应用服务/Repository双重校验；未知owner不能由学生认领。教师演示只管理当前宇宙。P2由服务器登录会话、当前班级成员资格和owner_enrollment_id判断；其他班级教师不能修改此班级星球。

建议扩展UniverseLayoutService为单条目配置命令，提交universeId、planetId、motion、必要的新锚点和expectedLayoutRevision。Repository在ownership+universes事务内重复检查角色、条目存在与可写状态、参数范围和revision，只更新目标条目并递增layoutRevision。现有拖拽保存也使用相同revision，避免教师改速度与学生拖拽互相覆盖，或发生A→B→A变化后误接受旧请求。云端采用条件更新/事务和服务授权，并记录教师操作审计。

失败保持已保存配置，冲突明确提示刷新后重试；拒绝请求不得改变其他条目、原图、作品revision、装饰或ownership。不能只靠前端禁用按钮实现权限。

## 开发顺序与验收

列入P1b近期增量，建议先完成单颗设置，教师批量操作后补；P2接入真实登录时替换授权适配器。该增量不包含在最初P1b的7–12人日估算内，开发前重新估时。

1. 契约与迁移：注册模式/预设/有界参数，准备旧Universe、完整备份与冲突fixture。
2. 领域计算：静止、四种轨迹、三档范围、速度档与完整路径边界；0秒位置一致、seed稳定、周期闭合。
3. 应用与存储：权限校验、单条目原子保存、layoutRevision、拖拽协同和刷新/ZIP恢复。
4. 渲染与交互：预览/取消/保存、平滑切换、命中真实运动位置、聚焦跟随、主体装饰同步及全景包含完整轨迹。
5. 浏览器验收：学生本人可配置、他人直接调用被拒绝、教师控制所有本班条目、未知owner拒绝、双窗口冲突、失去权限时取消操作、保存失败回退、20多颗混合静止/慢速/快速，以及暂停/减少动态效果。

每个模块完成后先测试再推进。参数切换应更新节点运动状态，不因每帧运动保存数据库、重载全部纹理或重建宇宙。快速模式不增加粒子预算。性能、全景取景和可点击性需要目标机房设备复测；不得以任意手绘轨迹或浏览器软件WebGL结果替代验收。
