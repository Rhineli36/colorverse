# 15 · 宇宙氛围与背景相机

日期：2026-10-09。沿用 React / PixiJS 统一渲染，新增独立宇宙景观模块，不修改作品、素材协议或布局锚点。

2026-10-11增量：当前星云已改为单张全景、完全同步相机并扩展外围范围，见[30](30-default-art-and-student-entry.md)、[31](31-classroom-space-and-boundaries.md)；新增四颗恒星和两处较大黑洞，见[34](34-universe-landmarks.md)。下方初版资源记录保留作为历史，不代表当前星云平铺或纹理总预算。

## 最终视觉约定

- 蓝青、紫色纹理星云与深空星野；亮星轻微闪烁，24颗小星星沿不同的平滑有界路径游移。
- 流星每隔 **90–120秒** 出现一颗，随机序列改变间隔、起点与方向。首次出现也等待该间隔，每次约1.65秒。按有效运行时间计算，暂停或后台页面不消耗等待时间。
- 黑洞固定于宇宙坐标(1750,820)，有暗色中心、暖色吸积盘、弯曲光弧和绕行尘粒；为风格化二维景观，不改变星球位置、轨迹或作品颜色。
- **星云、星野、小星星和黑洞与星球共用相机平移、缩放**。放大时背景细节一起放大。流星保留远景划过屏幕的表现。
- 景观不参与点击和拖拽。进入内景或Studio时隐藏，不混入作品导出或缩略图。
- 暂停覆盖全部宇宙动态；系统减少动态效果保留静态景观，关闭流星、游移、闪烁与尘粒运动。

## 初版模块与资源（历史记录）

renderer的`atmosphere.ts`管理背景、世界景观和流星容器，`atmosphere-model.ts`提供噪声、流星时间表和小星星轨迹纯函数；不访问IndexedDB或写文档。

顺序为星云/亮星 → 平铺星野/世界星点 → 黑洞 → 学生星球/轨迹 → 流星 → 选区。星云和星野采用TilingSprite，只绘制可见视口；纹理坐标绑定宇宙原点，相机导航不生成纹理或重载场景。星云瓦片边缘渐隐。固定CSS星云已移除，只保留边缘暗角。

纹理挂载时生成、销毁时释放；Canvas像素计算不进入动画循环。新增纹理：768×512星云、128×128辉光、512×512星野，RGBA像素约 **2.56MiB**，不等于浏览器总内存。低质量星云384×256，亮星/游移星/黑洞尘粒10/8/16，常规24/24/48，流星最多1颗。低质量沿用RendererOptions，尚无独立画质选择UI。没有新依赖或外部下载。

主包约817KB、gzip约254KB，新增TilingSprite相关代码后超过当前800KB提示线；生产构建成功，拆包与机房性能按P1b继续验收。软件WebGL浏览器回归不是实机性能承诺。

## 验证范围

纯函数检查噪声连续性、300次流星间隔90–120秒、淡入淡出和变化位置、小星星轨迹有界/连续、低质量预算。浏览器检查真实间隔后的流星像素、安静时段动态、暂停、恢复、内景切换、原作品不变、减少动态效果与移动视口。相机检查将缩放/平移前后的星云像素投影到同一世界位置，验证图案确实同步，且generation不变、极远景覆盖。

实际结果见 [实现进度](10-implementation-progress.md) 和outputs/报告。既有四组浏览器脚本继续验证权限、24颗全景、进入、ZIP恢复及光环跟随。后续学生选择速度/轨迹仍按 [14](14-planet-motion-controls-plan.md) 推进，本次没有提前实现。
