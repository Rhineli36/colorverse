# 16 · 图片编辑、分区上传与场景复位

日期：2026-10-09。本增量沿用既有场景文档、独立图层、不可变原图、命令撤销和 IndexedDB 版本历史；不引入三维编辑器或新数据库。

## 交互与布局

- 左侧集中星球名称、署名、创作主题、介绍等文字，以及场景图层、图片上传和装饰选择；右侧集中主题色、背景、图片尺寸、调色与视觉参数。
- “星球外观”只上传外观图片，选择“替换星球主体”或“添加外观图片图层”。统一一个上传入口，移除重复的主体上传卡片。外观不展示内部背景上传或渐变控件。
- “内部空间”只添加内部图片；右侧主题色下方提供内部背景、纯色与“使用主题色渐变”，无需跨两侧查找颜色。
- 选中图片可直接拖动选框；角点缩放，右边与下边分别拉伸宽、高。右侧提供独立横纵缩放与比例锁定；后续17增量移除冗余的放大/缩小按钮。角点在比例锁定或按 Shift 时按原比例缩放；边缘句柄允许单轴拉伸。
- “裁剪图片”打开原图预览，可拖选范围、选择正方形/4:3/16:9，或填写百分比。只有“应用裁剪”提交；取消不改变作品，“恢复完整取景”删除裁剪参数。拖动过程中只向渲染器传入临时变换，松开提交一条可撤销命令；Esc/指针取消放弃拖动，不在每次移动时重新加载纹理。
- 图层列表每行增加 × 删除；隐藏/显示与删除统一放在列表下方（17增量），参数区重复入口移除。删除可撤销，关联热点同时移除，附着装饰解除绑定并保留世界坐标。外观必须保留一个主体图片，接受后的成长图层仍通过成长记录撤销。

## 外观蒙版

外观主体使用正方形视口和圆形蒙版；宽图或高图先保持原比例以 cover 填满视口，再显示圆形区域。外观追加图片同样裁入主体的蒙版，光环、光晕和卫星等装饰可显示在蒙版外。内部图片继续按原始宽高比显示，不强制成为星球。

Studio、内部预览中的外观场景以及宇宙总览共用这条规则；宇宙也渲染追加的外观图片，并保持相对主体的位置、裁剪和调色。18增量将蒙版改为固定场景中心与直径，图片在蒙版内独立移动、缩放与动画，拉伸不改变圆形轮廓。自动适应与透明度下限见[18](18-fixed-planet-frame-and-image-fit.md)。此功能是二维图片取景与形状裁切，不宣称实现真实球面贴图或三维光照。

裁剪纹理仅引用原展示纹理的局部区域，共享纹理源；清理局部纹理不销毁共享原图。不会覆盖原始素材、改变 hash 或生成烘焙图片。

## 协议增量

图片图层的 source 增加可选参数，旧文档省略时表示完整图片：

```json
{
  "assetId": "原素材 ID",
  "crop": { "x": 0.25, "y": 0, "width": 0.5, "height": 1 }
}
```

x/y 为原图归一化左上角，范围 0–0.99；width/height 为归一化尺寸，范围 0.01–1。领域层要求 x+width、y+height 不超过 1。结构契约仍由 Zod 生成 Schema，跨字段边界在领域层校验。

存在 crop 的星球声明 `image-crop@1` 必需能力；恢复完整取景、删除或复位后，如果两侧均无裁剪图层，移除该能力。ZIP manifest 汇总包内文档实际必需能力，导入还原参数及原文件；不支持裁剪的旧版本应拒绝编辑此类包，不能默默丢弃取景。保持 schemaVersion 兼容，新增能力控制兼容边界。

普通内部/追加图片的裁剪以原图坐标和原锚点定位；主体的圆形视口尺寸不随裁剪范围变小，以便改变取景时星球不会突然缩小。

## 复位与历史

画布上方按当前标签提供“复位星球外观”或“复位内部空间”。Repository 从现有 revisions 记录中读取数值 revision 最小的快照；没有快照时回退当前文档。复位恢复该侧背景、普通图层与热点，保持当前文字、主题色、另一侧场景、素材记录与成长历史。

已接受成长元素继续保留，已撤销成长的 tombstones 不被复活。复位通过普通编辑命令提交，可撤销回到复位前；旧素材继续保留，以便恢复原图。撤销可选 crop 时真正移除属性，而不是写入 undefined，保证 JSON 与严格契约一致。

“最初版本”是此浏览器首次保存/导入这颗星球的版本，不是上次保存；ZIP 不携带完整本地 revisions，导入副本的最初版本是导入时的作品。清理浏览器数据仍会丢失本地历史，应导出作品备份。正式版本选择器、长期版本归档和大历史查询优化留在后续阶段。

## 实际验证

- 模块测试：图片编辑 6 项、场景复位 3 项、新增 ZIP 裁剪往返 1 项；本地 Repository 测试增加最初版本读取断言。连同既有模块共 57 项通过。
- `tests/image_tools_browser.py`：17 项生产浏览器检查通过，包含宽照片圆形蒙版角落像素、宇宙总览裁剪/蒙版像素、原文件 hash、缩放/拉伸、裁剪与取消、精确撤销重做、拖动预览不重载、角点缩放、逐行删除/撤销、独立复位、刷新、ZIP 独立上下文恢复及移动视口无横向溢出。
- 测试在隔离的 Chrome/SwiftShader 上下文执行，不覆盖用户正在编辑的作品；运行时与资源错误为 0。其余回归结果记录在 [10-implementation-progress.md](10-implementation-progress.md)。
