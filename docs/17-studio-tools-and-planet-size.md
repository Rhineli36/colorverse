# 17 · 顶部创作工具与星球尺寸范围

日期：2026-10-09。沿用已有编辑命令、原素材、场景协议和布局权限；本轮调整创作入口与展示规则。

## 编辑侧栏

外观与内部空间的图片导入始终放在左侧栏顶部。当前按19增量调整为图层独立常驻，下方仅“星球信息 / 装饰”共享选项卡与滚动区域，默认装饰。详见[19](19-student-edit-entry-and-persistent-layers.md)。文字与装饰不再把导入和图层列表挤到页面下方。

隐藏/显示和删除当前图层的操作紧接图层列表下方，移除右侧远距离的重复操作区；每行 × 删除快捷入口保留。长列表在最高min(190px,20vh)的区域内单独滚动，操作按钮不会被几十个图层推远。删除继续支持撤销，并沿用最后一个外观主体与成长图层的约束。

右侧保留主题色、内部背景和图片取景工具，将“图层参数 / 基础调色”改为共享区域的选项卡；透明度位于调色选项卡，非图片仍可调整透明度，选择新图层默认打开参数。选项卡使用 tablist/tab/tabpanel、选中状态和方向键/Home/End，切换不会提交文档或清空作品参数。

图片尺寸区域去掉独立的放大、缩小按钮；保留比例锁定、横纵缩放滑条、画布拖拽/角点缩放和裁剪。沿用16的原图不可变与撤销规则，没有重复添加新的缩放入口。

## 宇宙展示尺寸

采用用户给出的较窄范围：以标准星球为1，展示缩放为0.8–1.2倍，最大直径与最小直径之比不超过1.5。此处限制的是 UniverseEntry 对应的星球整体展示大小；图片图层的局部缩放/取景、相机放大缩小和卫星轨道保持各自语义。

统一 `planetDisplayScale` 在渲染容器、鼠标命中判断与轨迹边界计算中使用，确保画面大小、可点击范围与全景镜头一致。新建星球的 scale 为1，六颗新演示作品分别使用1.18、1.02、1.08、0.96、0.88、0.82。

旧作品/备份仍接受既有0.1–2的存储契约；展示时将超出范围的值收敛到0.8或1.2，不改写旧 scale、锚点或学生原图，也不增加数据库迁移。以后增加正式展示尺寸控件时，仅允许保存0.8–1.2，并沿用本人/教师的授权及并发检查；本轮没有添加新的尺寸权限入口。
