# 25 · 八种预制成长元素与创作体验优化

日期：2026-10-10。延续23/24确认的预制路线；本轮从2种扩至8种，并改善学生上传、选择、保存与恢复的操作。最终约30种及API定制仍是后续范围，保留02的本地优先架构。

## 本轮实现

| 类别 | 已登记造型 | ID |
| --- | --- | --- |
| 植物 | 微光花、发光叶片、月光蘑菇 | glow-flower / luminous-leaf / moon-mushroom |
| 矿物 | 晶体 | crystal |
| 天空 | 彩色云朵 | cloudlet |
| 地形 | 漂浮岛 | floating-island |
| 光效 | 星光种子 | star-seed |
| 轨道物件 | 轨道石 | orbit-stone |

种类/名称/关键词/能力声明统一登记在contracts/growth-presets。固定几何由domain/growth-geometry提供，SVG选择卡和Pixi场景消费同一数据；renderer不再通过“不是花就画晶体”的分支处理所有元素。保留原有两种形态，新类型有独立轮廓、透明叠加与受限光效。每种最多16个几何片段，基础框200px，不引入外部纹理或每元素独立动画循环。

本批为程序图形原型，由项目开发代码绘制（AI协助代码开发），没有调用图像生成模型，不是学生原创，也不是30种正式美术素材。GrowthLibrarySpec记录版本、来源、基础尺寸、片段预算及参数契约；项目许可尚未指定，不给第三方资产假填授权。后续绘画元素必须登记作者/许可、hash、透明图/缩略图、按需加载与ZIP闭包。

新增六种声明growth-library@1，新读者兼容原有记录；旧读者可能拒绝新能力或ID，不能直接回滚读取。结构/预设版本保持1.0.0；新规则使用showcase-rules-v2，仅用于新建议，已有事件不重抽或改变造型。手写草案与生成Schema的预设列表一致性有CI测试。

## 学生实际操作变化

1. 上传时显示原图预览、尺寸和大小；标题为空时按文件名建议，可自行修改。小屏的取消/保存操作固定在窗口底部，表单内部滚动，背景不跟随滚动。
2. 成长建议提供8张有名称的造型卡，可以选择喜欢的轮廓，再调颜色、位置和大小。推荐只是一项起点，学生不必接受随机结果；不通过重复提交无限刷取。
3. “保存预览调整”只保存提案，尚未加入场景；顶部“保存”也会保留当前预览。刷新后从作品的“继续预览成长”恢复，再决定接受/跳过。未保存的调整明确显示状态，本轮不是自动保存预览。
4. 接受后图层和历史显示具体元素名称，继续支持来源作品与补偿撤销。图层参数仍可编辑。预览修改只能保持原图层ID、数量和所属场景，不能借更换造型移到另一场景。
5. 展示作品每页最多8件，翻页释放上一页图片URL；新上传自动回第一页。避免一打开就读取数百份缩略图，作品档案及原图仍完整保留。

## 下一步体验方向与优先级

| 优先级 | 学生困惑/需求 | 下一增量与验证方式 |
| --- | --- | --- |
| 高 | 不清楚保存后该做什么、预览尚未应用 | 连贯的“已存作品→选择成长→进入内景欣赏”指引；让画布和当前提案更靠近，验证首次使用能独立走完，不把教师课程步骤混进展示流程 |
| 高 | 自己的星球缺少个性化运动控制 | 按14实现静止/慢速/快速及受控轨迹；本人/教师权限、位置冲突、刷新恢复和减少动态效果逐项验收 |
| 高 | 浏览器存储与多设备不一致 | 清楚显示本地保存、最近导出备份，优化ZIP恢复反馈；正式账号/共享云另按P2实现，不能暗示本地保存等于全班可见 |
| 中 | 素材有数量但缺少美术质感 | 用真实学生授权样本校准8种，再增加至8–12种；比较暖/冷/浅/深背景及小尺寸清晰度，完善纹理与光效，最后扩约30种 |
| 中 | 作品变多后难以整理 | 档案搜索/筛选/编辑与可恢复删除；删除必须检查成长/热点引用与历史原图，不能直接删Blob |
| 中 | 低性能电脑容易卡顿 | 实测纹理LRU、LOD、全局滤镜/粒子预算及低画质档，保留P1b机房门槛；本轮分页不代表300颗性能已通过 |
| 后续 | 学生想创造专属元素 | 独立API设计入口、异步生成/配额/授权/校验/预览接受；模型超时不阻塞作品保存，密钥不进入前端 |

这些方向为项目内体验判断，不以学生真实访谈/课堂实测结论冒充证据。先完成本轮可验证的操作改进，再逐项推进；不同时引入全部功能。

## 验证与边界

新增5项模块检查覆盖登记表/草案一致性、8种有界且不同的形态、规则候选覆盖、新预设保存/冲突/非法改场景、能力兼容；加强既有ZIP测试以使用漂浮岛和新能力。全套95项模块、TypeScript、ESLint及生产构建通过。

新增8项浏览器检查覆盖上传预览/标题、8种选择卡、实际WebGL不同轮廓、预览保存与刷新、顶部保存、命名/来源/ZIP、小屏固定操作栏及分页；原有展示13项、核心14项、学生入口6项回归通过。使用隔离浏览器数据及合成图片，无外发学生作品。累计独立浏览器报告151项，重复复测不重复计数。

目标机房、美术素材实样、完整权限/共享系统与自动保存预览仍未验收。生产主包约875KB/gzip273KB，既有第三方注释与体积提示保留为P1b拆包任务。发布结果见[10](10-implementation-progress.md)。
