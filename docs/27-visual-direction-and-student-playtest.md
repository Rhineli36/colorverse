# 27 · 三处界面的视觉方向与学生体验测试

## 建议的共同方向

建议采用「极光观测站」：深靛蓝空间，青蓝/紫罗兰的局部辉光，暖橙用于创作与保存动作。宇宙像开放的色彩展览，星球像学生私人世界，工坊像能亲手制作这个世界的工作台。

可比较两个备选：偏植物、漂浮岛与柔和光点的「梦幻生态宇宙」，以及更鲜明紫青对比、几何轨道与仪表边框的「霓虹创作舱」。先做同一套三个页面的静态对比，选定共同语言后实施。默认主题只改变界面与公共景观；学生原创图像、主题色、图层和运动配置独立保留，个性不被公共主题覆盖。

共同视觉规则：主要操作有明确的实色按钮；次要控件降低视觉重量；高亮集中在当前对象/工具。功能文字保持直白中文，颜色搭配文字、图标与选中边线，不只靠颜色区别。装饰性细线、轨道弧和编号用于标题与分区，正文与图片周围保持安静；所有文字面板有足够稳定的底色。

## 宇宙：第一眼想探索

| 改进 | 具体表现 | 学生操作与保留条件 |
| --- | --- | --- |
| 景深与空间构图 | 星云明亮区域集中在远处，深空留出呼吸空间；用不同大小与亮度的星点形成前后层次 | 所有景观继续绑定同一相机；保留缩放同步，先通过静态层次改善空间感 |
| 星球轮廓 | 调整当前较厚的暗色底圈，候选为贴合主体的柔和边缘光与细轮廓；选中时短暂增强边线 | 选中/可拖拽状态清楚；固定蒙版、展示尺寸0.8–1.2、原创取景不变；避免把整幅作品染色 |
| 信息更轻 | 常态保留简洁导航；悬停或键盘聚焦出现名称、作者与三枚色卡；选中后展开欣赏/进入/运动入口 | 移动端用点选；编辑和进入明确分开，按钮不会遮挡星球或缩放控件 |
| 有目的的探索 | 可评估小型位置总览和「回到我的星球」更醒目的入口；筛选时给匹配对象柔和标记 | 不自动重排星球、改变教师布局或启动不可控漫游；世界总览可以随时恢复 |
| 稀少的惊喜 | 黑洞改善吸积盘明暗和空间层次，偶发流星有一次清晰的尾迹 | 保留90–120秒一颗、暂停/减少动态效果和原预算；不提高流星频率来制造热闹 |

保留38%适度聚焦与现有平滑镜头，不做强制贴脸拉近。宇宙目前已具备基础氛围，首轮重点是构图、轮廓与信息层级，不把所有候选同时加入。

## 星球：每个人拥有可欣赏的小世界

外观与内部空间分别设计。外观用少量可选边缘光、薄雾或卫星强调性格；球面明暗可作为可关闭的展示选项评估，默认保持学生绘画取景与色彩，不自动把原图扭曲为球面。

进入内部后，先看到完整创作场景，姓名/标题/独白作为简洁的入场说明，自动让出欣赏空间。热点从统一的小标记改进为有图标和短标题的邀请，例如「看这幅作品」「一段创作想法」；选中后才出现完整内容。画面密集时提供安静的作品列表入口，不能只依赖发现发光点。

档案弹窗可采用展签结构：作品图为主，标题、说明、日期、关键词与主题色在稳定底色的侧栏，切换作品时位置一致。减少动态效果时保留静态过渡；手机使用单列和固定关闭按钮。关闭弹窗回到原位置，退出内景回到原宇宙镜头。

成长元素优先改善8种已有造型的轮廓、纹理与发光边缘，再逐批扩展。接受成长后可在新增元素处播放一次约0.6–1秒的显现，随后停下并提供撤销/来源入口；这是未来表现提案，不能在提交时自动接受、随机重抽已保存结果或掩盖保存失败。

## 工坊：让人想动手，也容易找工具

保留顶部图片导入、常驻场景图层与就近隐藏/删除，文字信息和右侧颜色/画面编辑继续分区。欣赏模式与编辑模式保持两个明确入口。

| 部位 | 建议表现 | 行为要求 |
| --- | --- | --- |
| 外观/内部切换 | 更醒目的两张小型预览卡或带缩略图的分段按钮，显示当前编辑对象 | 所有上传、复位和适应行为只作用于当前侧，不交叉混入入口 |
| 装饰库 | 用真实小预览替代只有文字的按钮，按粒子、光影、光环/卫星分组；保留名称 | 大一学生能先看效果再选择；重复添加有明确反馈，添加后能立即在图层栏找到并删除 |
| 图层栏 | 当前层显示小缩略图、名称、可见状态，选中边线更明显；操作始终靠近列表 | 不把隐藏按钮重新移回远处属性区；键盘和手机仍可操作 |
| 画布 | 放大工作区域，参数面板可折叠；拖动图片时出现少量对齐辅助线 | 蒙版固定，辅助线只辅助定位；不覆盖原图或更改裁剪语义；有明确恢复面板入口 |
| 参数 | 更清楚的分组、数值和选中反馈，常用工具先出现，进阶项折叠 | 持续保留色彩与渐变同侧、拖拽/滑条、撤销/复位，避免重复按钮 |
| 保存与成长 | 顶部常驻「保存中/已保存到此浏览器/保存失败」；成长预览旁显示接受后的位置和下一操作 | 状态由真实保存结果驱动；预览保存、应用和备份各自明确，不能把本地保存描述为云同步 |

面板可以用有底色的半透明材质、细彩边和选中工具局部辉光；先验证轻量样式，避免大面积实时模糊影响画布反馈。工具动画先采用约120–220ms的短过渡，不让每个控件持续闪动。

## 明天测试建议

先按学生身份自然完成四段任务，不预先解释每个按钮；本机与在线使用各自存储，先选定一个地址完成整段，再单独验证ZIP迁移。

1. 从宇宙找到自己的星球，欣赏、进入内部、查看作品并返回，观察是否迷路或镜头突兀。
2. 从「编辑你的星球」上传外观，自动适应、移动/缩放取景、加装饰、隐藏/删除、撤销与复位；切换内部后同样检查上传入口。
3. 添加展示作品，选择成长造型，保存预览、刷新继续，再接受或跳过；查看来源和新图层，检查下一步是否明确。
4. 设置运动，返回欣赏、暂停/拖拽、刷新；导出完整宇宙ZIP，在独立测试浏览器中导入并核对。教师/同学权限另用隔离上下文验证。

每次卡住只记录「所在页面 → 操作 → 预期 → 实际」及一张关键截图；附设备/视口、地址。按入口难找、命名不明、距离太远、无反馈、视觉不舒服分类。若能邀请一位首次使用者独立体验，可检验教师熟悉流程后容易忽略的困惑；目前未进行真实学生测试。

## 落地顺序与验收

先修复明天发现的阻断操作与误解，再落实保存/备份反馈；随后做三屏视觉草图，统一颜色、面板、按钮和展签；再小步实现轮廓/构图、装饰预览和成长反馈。每次视觉改动保留前后截图，并按涉及模块回归，不一次换掉整个界面。

照片作品与透明绘画都要检查；主色/浅色/深色作品、长中文名称和390px手机下，工具仍可找到，画面不被遮挡。地图景观与作品颜色分开，作品hash、参数、所有权和布局不因皮肤更新变化。动画遵守暂停、后台与减少动态效果；性能按[08](08-quality-and-decisions.md)实机验收，效果密度受[15](15-universe-atmosphere.md)预算限制。

本轮仅完成方案与参考检索，未新增已实现功能或测试数量，不调用图像生成/API，也不把目标设备或学生偏好宣称为已验证。
