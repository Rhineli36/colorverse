# 28 · 生长元素专用编辑流程

日期：2026-10-10。记录用户截图及补充反馈，待明天体验测试后实施；本轮只更新设计。延续[24](24-showcase-growth-first-slice.md)的作品来源与成长事件、[25](25-growth-library-and-experience.md)的预制库，以及[27](27-visual-direction-and-student-playtest.md)的三屏视觉提案。

## 用户要求

提交一次展示作业后，星球先自动出现一个新元素；点击元素进入专用编辑状态。此处只修改该元素，不显示内部环境、背景、全场景调色或其他图层的设置。库最终提供约30种已制作元素，学生可自行换选。当前8种为原型，不宣称已有几十种。

**删除元素编辑里的水平位置和垂直位置滑条，直接在画面拖动定位。** 画面中的选中轮廓和拖拽反馈应清晰，拖一次对应一次撤销。位置不必通过远处的表单调整；键盘方向键可作为微调补充，仍不增加位置滑条。

## 按截图划分区域

| 区域 | 内容 | 操作范围 |
| --- | --- | --- |
| 红框：上方元素库 | 有真实缩略图和名称的造型列表，分类/滚动，当前造型明显选中 | 为当前元素换造型，保留作品来源与元素身份，不因换选新增一层 |
| 中央画面 | 星球内景作为上下文，当前元素突出，可拖动与调整大小 | 只命中和编辑目标元素；其他图层作欣赏背景，不能误拖环境 |
| 蓝框：元素细节 | 颜色、饱和度，以及该造型支持的动态、粒子/光影效果；实时预览 | 只作用于当前元素，按预设能力显示选项；换造型保留兼容参数 |
| 绿框：操作区 | 确定、撤销一步、重置；可补充取消修改/关闭 | 重置只恢复此元素进入编辑时的基线；新生元素基线是本次生成结果。确定成功后有保存反馈，失败保留可重试草稿 |

静止/运动可放在蓝框动态组，绿框保留主要确认操作。这里控制元素自身漂浮、旋转或呼吸，与[26](26-planet-motion-first-slice.md)的整颗星球运行轨迹分开。小屏按元素库→画面→参数排列，确认操作就近固定，目标元素保持可见。

## 自动出现与保存语义

用户明确要求自动出现；首版设计建议先显示带「新生 · 待确认」标记的可编辑预览，点确定后正式应用，延续学生确认机制。此语义是本轮实现建议，不能冒称用户已选择立即接受或待确认。明天按测试反馈定稿。

展示作品保存成功后自动准备一次确定性预制提案，不再要求学生先去列表点击生成。作品保存和成长准备分别显示结果：成长失败不丢作品，可重试；同一作品仅一个成长事件，刷新不重抽、不重复增加元素。草稿可以保留并再次打开；取消本次调整恢复进入时状态，跳过本次成长须有明确入口。

已经接受的元素再次点击也使用同一专用编辑器。确定更新原元素，不重新提交作品或产生第二次成长；保持来源、归属和补偿历史，按revision检查并发。欣赏模式点击先展示元素/来源，有编辑权限时提供明确编辑入口；只读访客不能误进入可写状态。

## 实施与验收

先实现专用编辑会话与当前8种造型，再校准并扩充约30种；API设计元素仍留后续。保留原有环境编辑入口与常驻图层，不在元素编辑会话中混入其参数。

验收包括：提交后出现一个元素；点选打开专用工具；造型/颜色/动态不影响环境；没有横纵位置滑条；拖动/撤销/重置/取消/确定范围正确；刷新与ZIP保留来源和参数；重复提交/打开/确认不增层；保存失败与并发不覆盖；手机及键盘能完成。测试数量在实际实现后记录，本轮不增加运行测试。
