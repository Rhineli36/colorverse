## 用户要求

提交一次展示作业后，提交流程结束；星球自动出现一个小的新元素，播放一次生长动效。学生可继续欣赏，也可点击新元素进入专用编辑状态；不强制提交后立即打开编辑器。此处只修改该元素，不显示内部环境、背景、全场景调色或其他图层的设置。库最终提供约30种已制作元素，学生可自行换选。当前8种为原型，不宣称已有几十种。

**删除元素编辑里的水平位置和垂直位置滑条，直接在画面拖动定位。** 画面中的选中轮廓和拖拽反馈应清晰，拖一次对应一次撤销。位置不必通过远处的表单调整；键盘方向键可作为微调补充，仍不增加位置滑条。

## 按截图划分区域

| 区域 | 内容 | 操作范围 |
| --- | --- | --- |
| 红框：上方元素库 | 有真实缩略图和名称的造型列表，分类/滚动，当前造型明显选中 | 为当前元素换造型，保留作品来源与元素身份，不因换选新增一层 |
| 中央画面 | 星球内景作为上下文，当前元素突出，可拖动与调整大小 | 只命中和编辑目标元素；其他图层作欣赏背景，不能误拖环境 |
| 蓝框：元素细节 | 颜色、饱和度，以及该造型支持的动态、粒子/光影效果；实时预览 | 只作用于当前元素，按预设能力显示选项；换造型保留兼容参数 |
| 绿框：操作区 | 确定、撤销一步、重置；可补充取消修改/关闭 | 重置只恢复此元素进入编辑时的基线。确定保存本次修改，不承担首次生成/接受元素的职责；失败保留可重试草稿 |

静止/运动可放在蓝框动态组，绿框保留主要确认操作。这里控制元素自身漂浮、旋转或呼吸，与[26](26-planet-motion-first-slice.md)的整颗星球运行轨迹分开。小屏按元素库→画面→参数排列，确认操作就近固定，目标元素保持可见。

## 自动出现与保存语义

用户随后明确补充：提交归提交，提交完自动出现小元素，点击才进入编辑。采用「提交成功 → 自动生成并保存一个默认小元素 → 一次显现动效 → 可选点开编辑」。取代本轮先前的待确认预览建议；这是后续交互调整，目前运行程序仍使用24/25的手动建议/接受流程。

展示作品保存成功后，使用确定性预制规则自动完成默认成长，不要求先去列表点击生成或再确认接受。提交入口清楚说明会产生一个成长元素；本地预制自动成长与后续模型生成分开，模型建议仍需学生确认。作品保存和成长分别显示结果：成长失败不丢作品，可重试；达到既有图层/成长上限时保留作品并说明原因。同一作品仅一个成长事件，默认元素、来源和接受记录原子保存，刷新不重抽、不重复增加元素。

新元素以小尺寸落在可见区域；建议用约0.6–1秒的淡入、舒展或少量光点提示其位置，然后恢复日常表现。动效只发生于本次成功生成，不在每次刷新/打开时重播；暂停或减少动态效果时直接显示清晰静态结果。动效不改变已保存色彩，不遮挡提交成功反馈，不阻止其他操作。

点击可编辑元素进入同一专用编辑器；确定更新原元素，不重新提交作品或产生第二次成长。取消修改恢复打开时的元素，关闭编辑器不撤销已完成提交，也不删除自动生成的元素。保持来源、归属和补偿历史，按revision检查并发。学生可编辑自己的元素，教师沿用授权范围；只读访客点击查看元素/来源，不进入可写状态。

## 实施与验收

先实现专用编辑会话与当前8种造型，再校准并扩充约30种；API设计元素仍留后续。保留原有环境编辑入口与常驻图层，不在元素编辑会话中混入其参数。

验收包括：提交结束后自动保存一个小元素，动效播放一次且不强制编辑；点选打开专用工具；造型/颜色/动态不影响环境；没有横纵位置滑条；拖动/撤销/重置/取消/确定范围正确；取消编辑保留提交与默认元素；刷新与ZIP保留来源和参数；重复提交/打开/确认不增层；成长失败/额度上限不丢作品；保存失败与并发不覆盖；手机及键盘能完成。测试数量在实际实现后记录，本轮不增加运行测试。
