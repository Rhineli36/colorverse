# 32 · 作业展示优先与新元素显现

日期：2026-10-11。延续[29](29-automatic-growth-and-element-editor.md)的自动生长与独立编辑会话，按用户体验反馈调整进入顺序与动效节奏。

## 学生流程

1. 提交自选展示作品后保存原作，再由现有本地规则生成一个默认小元素，自动返回星球内部欣赏模式。
2. 新生元素从四分之一尺寸和微光开始，约4秒内平缓舒展至正常大小；同色光圈与四个微小光点展开、消退。短暂提示说明点击查看作业，操作无需等待动画结束。
3. 在画面点击元素或「查看作业」入口，先打开对应原作的展示窗口。展示不改变星球、素材或revision。
4. 展示下方「返回星球」关闭窗口；学生本人或教师可点击「编辑元素」，进入既有专用编辑器。其他学生可以欣赏作品，不能进入可写编辑。
5. 修改后再次点元素仍显示原作。元素造型改变不改变作品链接、原图或出生记录；原展示列表的主动编辑入口保留。

这里的作业是学生自选展示作品，正式课程作业提交系统沿用独立流程，本轮没有改其接口。

## 来源、权限与兼容

通过已接受GrowthEvent的archiveEntryId、sceneKind和layerId解析当前元素，使用当前图层而非出生外观。画面点选带入具体layerId，找不到时不转而编辑其他元素。撤销生长、删除元素或无关联的档案仍可展示原作，不提供失效的编辑入口。进入与保存继续检查归属及revision。

作品先保存，生长失败时仍返回内部欣赏并保留作品和既有重试说明。沿用同一作品只生成一次的规则、上限与旧v2预览兼容，没有新增成长事件或协议版本。

## 动效与资源

约4秒按既有共享渲染时钟计时。只在本次成功生成时播放；刷新、重新进入或完成编辑不重播。减少动态效果时直接显示静态元素。新生光圈与光点共用一个临时Graphics，完成或场景销毁时释放；不增加纹理、独立ticker、持久粒子层、逐帧存储或外部API请求。

场景异步加载完成后确认仍为当前renderer，避免旧场景启动新生动画。软件GPU或低帧率下现有时钟限步可能延长实际墙钟时间，目标机房的流畅度仍需实测。
