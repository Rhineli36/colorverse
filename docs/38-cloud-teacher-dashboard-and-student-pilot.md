# 云端教师管理、学生上传试用与 30 种成长元素

日期：2026-10-11。当前入口：[云端课堂测试版](https://colorverse-dev.2999346.workers.dev/)。用户选择先使用 Supabase 私有 Storage；GitHub Pages 保持本地演示。

教师登录后出现“班级管理”，可查看每个班级的学生、星球、展示作品提交数、课程提交数、发起和收到的互动、最近提交时间。支持本周/累计、姓名/提交/互动排序、搜索和未创建星球/未上传/互动不足 5 次筛选。每周从班级时区的周一开始；参考目标不等于教师已发布的正式考核规则。作品与互动先分别聚合，避免连接多个记录产生重复计数。学生和不属于该班的教师不能读取管理统计；身份停用、成员停用和班级归档都重新核对。

每个学生在每班仅创建一颗云端星球。课堂作品页提交自选展示图片，保留原图及 SHA256，另外生成最长边 2048px 的 WebP 展示图；原图下载与展示都由 Worker 验证本班权限后代理，不提供公开对象 URL。当前单图 8 MB、1600 万像素，每颗星球 100 件/100 MB（原图与展示图合计）的试用上限。Worker Images 完整解码/重编码后才存储，PNG/JPEG/WebP 以文件字节识别。新作品产生一次成长，约 4.5 秒出生动效；点击元素先展示作品，点击“编辑元素”后修改造型、颜色、大小、运动和直接拖动位置。保存使用修订号，冲突时要求刷新，不覆盖其他窗口修改。

支持班级内其他人的星球/作品点赞、预设表情和文字留言。重复点赞/表情和同一提交请求不重复计数，自身互动不计入且接口拒绝。当前只有添加互动，取消点赞、删除/举报留言、关注、浏览全班记录与每日精选仍待实现。统计反映实际写入的记录，不保证互动质量或防刷；开课前仍需补齐管理规则。

成长库从 8 种扩充为 30 种，保持原有 ID，新增水母、珊瑚、彗星、星蝶、冰晶塔、贝壳、莲花、微型星系等不同几何。造型与预览共享代码，每种最多 16 个基础形状，支持分类和搜索。本地原有元素编辑仍保留独立编辑、撤销和粒子细节。本次新增云端星球内部是课堂上传试用界面，原有本地完整创作工坊、宇宙布局和云端星球尚未自动互相同步；不上传浏览器里的演示作品或草稿。

数据库使用追加迁移 002/003，原 001 不变。身份读取角色增加统计所需的 SELECT；新的课堂写入角色仅有成员资料读取及星球/展示/互动业务表的必要操作权限，没有身份、班级或课程管理权限。两个 Hyperdrive 都关闭查询缓存并校验数据库证书和主机。Supabase 后端 Secret key 仅作为 Worker secret 使用，前端、Git 和源码包均不包含；私有 bucket 不设置浏览器直接读写策略。

原图与展示图写入失败会尝试清理本次对象；数据库提交结果不明时保留对象，重试通过请求 ID 查询已保存作品，避免删除可能已经提交的资源。尚未实现持久化上传意图、自动孤儿清理、作品删除、对象版本备份/恢复和配额管理界面。请求正文限流和字节上限已有，正式批量开放前仍需课堂人数下的网络、存储和限流验收。

已通过 22 文件 181 项模块测试、TypeScript、ESLint、生产构建、线上 7 项边界探针。新测试覆盖统计连接不翻倍、班级隔离、身份撤销、造型预算、互动去重、自身/外国作品拒绝、完整解码失败、上传上限和元素修订冲突。新测试加入真实 PostgreSQL 18 CI。

使用正规 Supabase Auth Admin 创建一个专用学生测试账户并绑定测试班，无邮件发送；登录资料仅保存在 Git 忽略的本机文件。真实学生登录、角色隔离、星球唯一性、上传、重复请求、原图 SHA256 往返、展示 WebP、元素保存及冲突、教师数据库查询统计交叉核对均线上通过。测试班保留 1 件明确标注“自动验收 · 青色练习”的测试作品；这是测试账户真实上传记录，不是正式学生作品。

独立浏览器验证通过：真实学生登录、先欣赏后编辑、30 造型、单元素运动保存、原图下载、刷新恢复、手机无横向溢出。教师界面采用隔离模拟会话展示真实 SQL 验证获得的统计行，完成搜索、本周/累计和手机布局检查；没有使用教师密码或冒充教师调用真实 API。此前教师登录由用户本人验证，教师端真实页面仍需用户用自己的账户核对。校园网络、正式学生批量登录、SMTP/找回密码和每日精选尚未验收。

官方接口依据：[Supabase 创建用户](https://supabase.com/docs/reference/javascript/auth-admin-createuser)、[私有存储权限](https://supabase.com/docs/guides/storage/security/access-control)、[Cloudflare Images binding](https://developers.cloudflare.com/images/optimization/binding/)。当前 [Images Free](https://developers.cloudflare.com/images/pricing/) 每月 5000 个唯一转换，超过后新转换失败而不自动收费；没有购买付费计划。
