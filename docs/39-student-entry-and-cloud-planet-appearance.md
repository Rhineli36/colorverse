# 学生登录入口、首次创建与云端星球外观

日期：2026-10-11。入口：[Cloudflare 课堂测试版](https://colorverse-dev.2999346.workers.dev/)。承接 [38 云端课堂试用](38-cloud-teacher-dashboard-and-student-pilot.md)。

登录成功后，班级卡片可以选择班级，醒目的「进入我的星球 →」按钮进入该班级的云端星球。教师/助教显示「进入班级管理 →」。入口只来自服务器验证的有效班级身份，待入班、停用或验证失败没有操作入口。多班级选择会传递到课堂页和教师查看学生的星球页。本地编辑未完成时不会直接离开编辑器。

首次进入且没有自己的星球时，显示「一键随机创建我的星球」。服务器从六套默认星球外观选择初始名称、颜色和外观；每个班级成员仅有一颗，重复请求返回同一星球 ID。创建后选中自己的星球，播放约 4.5 秒的出现动画，之后再开放编辑和上传按钮。减少动态效果设置下保留静态欢迎画面。未创建星球时不会自动选中同学的星球；仍可以主动浏览同学。已有星球再次确认进入时，直接选中自己的星球，不再显示创建按钮。

「编辑星球外貌与背景」可以改名、选择默认外观和环境色调；上传自己的星球外貌和内部背景。缺少任何一张图片时显示建议上传的提示，两张都上传后取消提示。上传的外貌优先于默认外观显示。图片在独立的私有 Storage 对象里，通过验证本班权限的 Worker 读取；请求正文以字节识别 PNG/JPEG/WebP，单图最多 8 MB/1600 万像素，完整解码后生成优化 WebP。外貌最长边 1024px，内部背景最长边 2048px。外貌显示为圆形，背景按场景容器裁切。这里的外貌/背景保存优化后的图；展示作业的原图保存/下载逻辑不变。

外观和图片只允许所属学生修改；班级、身份、成员状态在每次 API 请求核对。星球修订号防止旧窗口覆盖新修改，同一图片上传请求可重试而不重复生成。上传、外观修改和作业提交按成员事务锁串行，100 MB 配额包含当前外貌、内部背景、展示作品及作品原图。数据库承认新图片保存后才清理旧对象；事务失败前清理本次新对象，提交结果不确定时保留对象，避免误删已提交图片。清理失败暂记录日志，没有持久任务队列；对象定期清理和备份仍是后续工作。Storage 删除调用使用桶级 prefixes 数组，参考 [Supabase 文件删除](https://supabase.com/docs/reference/javascript/storage-from-remove)。

星球设置存于既有 planets.document JSON，不修改已应用的 001/002/003 迁移，不增加教师或学生数据库权限。云端课堂仍是独立的展示试用空间，本地完整工坊/宇宙布局尚未自动同步到云端。

验证：22 文件 184 项模块测试通过，TypeScript、ESLint、生产构建通过。新增真实数据库兼容的测试覆盖随机创建唯一性、本人权限、外观修订冲突、私有图读取、上传重试和旧对象替换。隔离 Auth/API 浏览器检查覆盖大按钮/多班级入口、4.5 秒动画、名称/默认外观/两张图片、再次进入选中本人、手机布局、教师入口；原有 7 项登录边界浏览器检查也通过。真实测试学生的线上 API 验证通过：原有星球不重复创建、外观保存、两张图片上传和重试、WebP 读取、匿名/异班拒绝，原有 1 件展示作业不变。首次新账户创建的页面使用隔离数据验证，没有删除或重置现有测试学生的星球。
