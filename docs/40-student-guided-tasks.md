# 学生的新手任务与星球设置分类

日期：2026-10-11。入口：[Cloudflare 课堂测试版](https://colorverse-dev.2999346.workers.dev/)。承接 [39 学生入口与星球设置](39-student-entry-and-cloud-planet-appearance.md)。

学生确认进入班级、创建自己的星球后，页面上方显示「我的星球任务」。已有星球的学生也会看到，已有图片、展示作品和编辑记录会自动计入，不要求重做。默认只显示下一步和进度，点击「查看全部任务」展开十项；可以自行选择顺序，不阻止直接上传作品。教师不显示新手列表。

| 任务 | 入口与完成依据 |
| --- | --- |
| 设计星球外貌 | 打开外貌设置；上传自己的图片后完成，默认预设不代替上传 |
| 点亮粒子氛围 | 打开氛围设置；保存星尘或萤火后完成 |
| 布置内部背景 | 打开内部背景设置；保存图片后完成 |
| 调整色调与细节 | 打开环境色、背景亮度/饱和度；通过此分类保存练习后完成 |
| 写下星球介绍 | 打开名称与介绍；非空介绍保存后完成 |
| 上传第一件展示作业 | 打开原有私有作业上传；已有作品后完成，保留约4.5秒生长动画 |
| 设计成长元素 | 首次上传后解锁；打开自己的元素编辑，保存修订后完成，支持造型、颜色、大小、运动和画面拖动 |
| 拜访同学 | 进入本班另一位学生的星球；服务端验证对象与身份后保存拜访标记 |
| 点赞或表情 | 跳转另一位同学的互动区；自己发送的有效点赞/表情完成 |
| 留下一条评价 | 跳转并聚焦留言输入框；自己发出的非空评价完成 |

班里尚无其他有效学生星球时，后三项提示「同学加入后解锁」，不代为互动或伪造完成。自己的作品尚未上传时，元素编辑任务明确提示先上传。收到别人发来的回应不算自己完成互动任务。上传和编辑进行中、作品展示弹窗打开或生长动画期间禁用任务跳转。重新进入时从云端读取进度。

设置面板分为外貌、粒子氛围、内部背景、色调细节、星球介绍五类。任务按钮直接选中对应分类并滚动到面板。保存只提交当前分类，上传图片不顺带保存其他分类尚未确认的文字或参数。上传图片仍优先显示，原有私有 Storage、本人编辑权限、图片优化、配额及修订冲突规则不变。介绍以普通文本显示，不作为 HTML 执行。

星尘和萤火在内部场景用24个无点击拦截的 CSS 粒子实现；系统减少动态效果设置下静止显示。它们是背景氛围，成长元素的运动仍独立设置。背景亮度限制在50%–150%、饱和度0%–200%，只调整背景，不修改作品原图或元素颜色；介绍最多1000字。服务端拒绝越界和未知字段。新字段及两项练习标记保存在既有 planets.document JSON，无新增迁移或权限提升；修改时保留私有图片 key、字节数和上传幂等标记。

进度属于功能引导，不用于课程成绩，也不等同于每周作业或全班拜访统计。图片、氛围、介绍等项目依据当前保存状态；色调练习与拜访保留体验标记。正式课程任务、全班遍历、每周至少五次有效反馈的统计仍需另行实现。完整本地工坊和宇宙布局尚未自动同步云端；本引导的按钮均进入真实云端课堂功能。

验证：TypeScript、ESLint、生产构建与22文件186项模块测试通过。新增数据库测试覆盖实际完成依据、收/发互动区别、无同学等待、本人和异班权限、拜访幂等、不影响图片修订号、字段边界以及私有图片信息保留。`tests/cloud_planet_entry_browser.py` 的9组隔离浏览器检查覆盖登录选班、首次4.5秒动画、无同学锁定、五类设计任务、作业/元素编辑、全部互动、进度恢复、手机布局和教师入口；两次完整流程通过。

真实学生测试账户线上6组检查通过：本人星球/原有作品、两张私有图片、氛围与色调及介绍保存、7/10自动进度、无同学的3项等待、手机布局与刷新恢复。此次仅修改既有测试星球的氛围/色调/介绍；原有1件展示作业和两张图片保留，没有额外上传作业、创建同学账户或发送虚构互动。线上7项入口与权限探针通过，前端无异常。
