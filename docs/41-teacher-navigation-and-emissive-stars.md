# 教师入口与恒星视觉区分

日期：2026-10-11。承接 [40 学生任务](40-student-guided-tasks.md)。

一般导航不再显示「教师演示」。仅当 Cloudflare 登录模块取得服务端验证的 active 班级身份、至少一项 membership 的 role 为 teacher 时自动显示该入口。客户端 user_metadata、当前本地布局角色或普通学生身份均不能开启；助教仍保留原有班级管理入口，但不显示本地教师演示。宇宙页的本地教师操作身份选择器也只在同一条件下显示，其他人显示「本地创作空间」。教师登录不会自动打开演示页或改变当前布局操作模式。

退出登录、成员角色变为学生/停用或身份验证无法完成时，立即隐藏入口、卸载已打开的本地教师演示页，并将本地布局角色复原为 student，避免继续以旧的教师角色操作他人星球。真实云端教师数据权限仍由现有 Worker/API 每次验证，演示页只管理本浏览器导入的作品与本地布局；它的说明文字现明确指向「班级管理」查看云端提交和课堂统计。GitHub Pages关闭云端身份模块，所以普通演示版不会出现教师入口。

四颗恒星的世界半径分别由400/780/950/620调整为700/1250/1450/1000，直径约为原来的1.5–1.75倍。减弱表面噪声对比，球面以0.66不透明度和加色模式显示，提高中心光强与外层日冕，让恒星体现自身发光，与实心的学生作品球体区分。恒星位置、学生星球/布局文档及黑洞不变。仍共享原来的256/512px表面纹理与光晕纹理，不新增图片下载、粒子数量或滤镜；放大后的覆盖像素更多，实际低端设备仍需课堂试用反馈，不能据此声称所有设备帧率相同。

验证：TypeScript、ESLint、生产构建通过，22文件186项模块测试通过。恒星原有边界/互相距离、低画质预算测试保持通过。一次GPU浏览器与并行数据库测试同时运行时，已有磁盘重开测试超过5秒；停止GPU竞争后以单worker完整重跑186项通过，未修改超时时限。

新增 `tests/teacher_visibility_browser.py` 使用隔离 Auth/API 验证游客没有教师UI、学生即使客户端元数据为teacher也不能开启、服务端教师身份自动出现、教师角色撤销后离开演示并收回他人编辑、退出登录隐藏，以及手机无横向溢出和恒星实际绘制。旧本地教师工具浏览器脚本通过 `tests/cloud_teacher_fixture.py` 建立隔离的服务端教师身份后再操作，需启用云端登录的构建；不使用真实教师密码，也不向真实Auth创建或提升账号。
