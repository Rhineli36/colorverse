# 试用前修复：登录续期与云端入口

日期：2026-10-12。承接 [41](41-teacher-navigation-and-emissive-stars.md) 与 [40](40-student-guided-tasks.md)。

就绪检查在已发布版本复现：正常刷新 Supabase 登录令牌时，AuthEntry 在验证开始就向 App 发送空会话，导致 CloudGallery 卸载；正在填写的作品标题、描述、图片选择和元素编辑状态丢失。已提交作品并未丢失。复现使用隔离 Auth/API，没有修改真实账户或云端作品。

现在同一身份续期和主动重新核对班级时，保留最近验证通过的页面，等待服务端核对结束，不重建课堂组件。核对期间账户入口显示验证状态，班级确认按钮暂禁用。每个实际课堂读写请求仍在 Worker 重新验证身份与班级权限。收到登出或不同身份事件立即清空；401、验证失败、返回身份与 SDK 会话身份不符、账户停用或成员权限撤销不会保留可操作的旧权限。延迟响应不能覆盖更新后的身份。失败后可以重新核对恢复。

此修复保证正常续期保留页面内未提交内容，不是跨刷新或跨设备的草稿持久化。明确退出、换账户、验证失败撤销访问、关闭浏览器仍可能清除未提交内容；已保存的云端记录独立保留。

CloudGallery 将上传表单、元素编辑、未保存星球设置、未发出的留言和正在进行的请求报告给 App。上述状态下，导航、重新确认进入课堂、切班/切星球、刷新作品及教师返回统计不能丢弃编辑；退出按钮暂不可用，页面关闭/刷新触发浏览器原生离开提醒。浏览器是否显示提醒取决于浏览器交互规则，不能据此代替持久化草稿。上传取消、元素取消、清空留言后可正常离开。

星球设置通过当前字段与服务器已保存文档比较是否有修改，切换五个分类保留各分类的内容。点击「完成设置」遇到未保存修改时要求逐项保存，或明确点击「放弃未保存修改」，避免把关闭误当作保存。单分类保存不会顺带提交其他分类草稿。请求/修订冲突规则保持不变。

真实云端写入已开放且身份仅有学生班级角色时，主导航显示「我的星球与作品」「宇宙演示」，收起本地完整工坊和模拟「课程作业」入口；本地演示内部不显示编辑星球/成长元素按钮。演示页显示明确提示和返回云端星球按钮。教师、助教、游客与 GitHub Pages 演示保持原有入口。完整本地工坊和宇宙布局仍未同步到云端，不能把本轮入口整理理解为完成云端班级宇宙。

新增 `tests/cloud_session_continuity_browser.py` 六组隔离检查：学生导航/手机布局、延迟续期与上传标题/描述/图片保持、导航与离开保护、星球设置与显式放弃、元素编辑保持、验证失败撤权/重试及不同账户/401/登出。模拟接口拒绝任何意外业务写入，不使用教师密码。

验证：186 项模块检查、TypeScript、ESLint、生产构建通过；新六组连续会话检查、原有九组学生引导、七组登录边界及六组教师入口回归均通过，共 28 组隔离浏览器检查。183 处文档相对链接和私密配置排除检查通过。部署后的验证记录在发布完成后追加。

下一轮试用门槛仍包括账户发放与密码恢复、作品删除/留言管理、数据库与私有图片联合备份恢复、两个真实学生互访与教师统计对照、校园网络和人数规模下的验证。当前继续使用既有免费服务，不创建收费资源或开通会员；需要升级时先向用户说明用途、费用与替代方案。
