# 班级演示数据与真实云端宇宙

2026-10-14。为展示星球、作品上传、互动与教师统计准备一组明确标注的演示账号和素材。

## 演示内容

新增 5 个学生演示身份，每个星球配置 5 件往届第三周展示作品，共 25 件。素材来自用户指定的 E 盘「6班 第三周 设计色彩作业」PPTX；提取其中嵌入的完整图片，保留作者分组和原作者署名，不修改源 PPTX。选取的嵌入图合计约 26.04 MiB，上传后的原图下载按 SHA256 对照；不包含未提供的 PSD/AI 等制作源文件。

账号名称为「演示学生 01–05」，邮箱采用 demo01–demo05@colorverse.test。密码由系统随机生成，仅写入 Git 忽略的本机 work/演示学生账号.txt 和恢复日志。所有身份均为当前测试班学生，不提升教师或管理员权限，不发送邮件。作品及星球图片继续存储于 Supabase 私有 Storage；素材、真实姓名、密码及导入日志不随 GitHub 代码提交。

配置流焰、潮汐、翡翠、紫雾、月岩五种星球。保存不同的光晕、粒子以及静止/慢速/快速和椭圆/圆形/往返/八字轨迹。演示点赞、表情与留言共 36 条，在文本或账号中明确标注演示用途，不代表真实学生反馈或成绩。仅针对这 5 个新增账号的星球互动，原 student01 账号的星球、作品与互动保持。

## 云端功能

真实班级宇宙直接使用班级接口返回的星球、外貌、运动、光晕和作品数。点击星球进入该学生的作品空间，权限和图片获取沿用班级核验。学生可在本人星球「星球运行」保存受限运行方式，查看即时轨迹预览；修改其他人的星球仍由服务端拒绝。旧云端文档默认静止，不因此次升级悄悄开始移动。

教师增加演示加速 ×3、星球诞生回放、成长元素生长回放。加速仅影响当前观看，回放保持约 4.5 秒，不创建星球、不上传新作业、不增加作品或互动计数。全局暂停和轨迹开关也不写入云端文档，系统减少动画时保留静态星球及轨迹。

班级互动亮点按有效点赞、表情与留言合计展示前 3 个星球；撤下作品对应的互动不计入，与教师收到互动统计保持一致。它是当前累计互动，不宣称每日评选或成绩排名。

班级宇宙首版自动排布，使用现有轨迹数学，最多同时显示 40 颗星球；超过时仍可通过完整列表访问。仅在可见区域推进动画，不逐帧读取数据库；原本地宇宙的拖放布局、平移缩放仍作为本地视觉演示，尚未迁移为云端共同布局。

新增色谱折扇、琉璃灯盏两种成长图形，共 36 种，库版本 1.3.0。共享 SVG/Pixi 代码图形与预算，原有 ID、已保存形状和原图保持。
