# 云端教师作品点评与评分

2026-10-14。展示作品中增加教师点评与 100 分制评分，学生继续通过点赞、表情和留言互评。教师与助教权限依据当前班级的服务端身份核验；学生无评分写入权限，包括自己的作品。展示作品点评与正式课程提交版本、课程成绩系统分开。

## 使用方式

教师从班级管理进入学生星球，点击作品或成长元素，在作品展示页填写「教师点评与评分」。可以只写点评、只打分，或者两者同时填写；评分范围 0–100，支持小数。已确认点评可以修改并保存为新版本。学生在同一作品展示页只读查看，学生互评留言独立于教师点评。

教师管理表增加累计点评进度、待确认演示建议数和已确认作品均分，可筛选仍有作品待点评的学生。均分只取正在展示的作品的最新教师确认分数，文字点评不纳入均分，演示建议不纳入均分，点赞、表情和留言数不影响分数。撤下作品保留点评历史但暂不统计，恢复后重新计入。

本次 5 位演示学生的 25 件往届作品预置建议分与具体点评，结合实际图片的配色、主体、层次和阅读体验提出修改方向。全部标记「演示建议 · 待教师确认」，不是原课程成绩，也不伪装为教师已打分。教师可以直接确认或修改后保存；预置脚本重跑保留既有点评，绝不覆盖教师确认。

## 数据与写入边界

005-showcase-reviews.sql 新建 append-only 点评版本表，记录作品、教师班级身份、版本、建议/确认来源、分数、文字和幂等请求。之前已应用的 001–004 迁移不修改。新表只向 reader 授予 SELECT、向 writer 授予 SELECT/INSERT，撤销 PUBLIC/anon/authenticated 的访问；禁止更新或删除点评版本的触发器保留历史。

作品班级、作者活跃状态、教师角色和撤下状态均在后端核验。每次保存锁定作品行并比较点评版本，冲突不会覆盖；同一请求和相同内容重试不重复创建版本，重复请求改内容会拒绝。客户端不能伪造 source/role。500 字学生留言规则和原图权限保持。

教师草稿未保存时保护关闭、Esc 和页面导航；可以明确放弃草稿。初次读取失败不能当成空点评直接写入。保存失败保留草稿和幂等键；遇到版本冲突后，可「读取最新点评（保留草稿）」核对最新结果，再明确保存。教师提交成功后，学生读取新结果，管理总览返回时刷新。
