- 五颗默认风格样本仍为只读参考，无虚构学生、作品数量或评分。它们展示在同一宇宙中，进入时明确说明是风格样本。

## 数据与署名的准确含义

姓名、学号来源为负责人提供的 `E:\6班 第三周 设计色彩作业` 中五份原始 PPT 文件名，和既有选材记录逐一核对。姓名及学号组合写入这五个受控账户的 `colorverse.users.display_name`，静态快照另有 `realName`、`studentNumber`。目前数据库没有单独新增学号字段；学号不参与登录授权，也不改变邮箱密码或角色。

这些账户用于展示往届作品，不表示原作者实际登录本系统或参加了本轮互评。既有演示建议分仍标为“演示建议／待教师确认”，不是原课程成绩。星球外貌和环境含 AI 辅助演绎。该实名要求优先于旧文档中“匿名案例”的描述，旧记录不因此改写成当时已经实名。

同步脚本仅允许既有五个受控案例身份和作品，不创建新用户、不修改其他真实学生的星球、作品或角色：

- `scripts/sync-exhibition-classroom.mjs`：复用既有 API 同步外观、环境与元素颜色；媒体记录保存在忽略目录的恢复日志中。
- `scripts/sync-exhibition-identities.mjs`：核对原文件署名与学号，在数据库事务中限定班级、enrollment、Auth subject 后更新展示名称。

## 修复与复现依据

1. **确认登录后仍被弹窗挡住**：登录状态到达后提前挂载课堂，加载中的 pending 状态使确认进入返回失败。现仅在确认进入后切换路由；进入过的课堂通过本机标记恢复。加载或未保存时相关入口明确禁用，避免点击无响应。
2. **聚焦倍率不一致**：视图请求倍率与渲染器聚焦倍率不同。现统一复用 `PLANET_FOCUS_ZOOM`，连续两次双击分别完成聚焦和进入。
3. **多张私有外貌串行等待**：新增大宇宙适配器原先串行取图，会因一张图片拖延整幅宇宙 ready。现并行预取，限制等待时间，失败时提示并使用默认图；默认图也失败时使用本机生成的简易球面替代图，提供重试。移除已隐藏但仍加载全部图片的旧星球列表，减少重复请求。
4. **一次作品图片网络失败**：真实案例浏览中出现一次图片失败，界面显示重试按钮。重读后图像可用；另用真实账户逐一 GET 五个案例首件作品图片均返回 200，首件 WebP 实际解码为 1513×2048。没有把网络失败隐去或以静态图片冒充后端成功。

本机测试使用 Windows Chrome、软件 WebGL；云端通过本机 HTTP 代理访问。代理由旧端口改为负责人提供的 18081，18080 为 SOCKS。此结果不是校园网络、比赛现场或无代理的中国大陆可访问性证明，也不是实体 iOS/Android 设备或全新电脑完整后端部署验收。

上一版的部分 Python 脚本仍针对旧列表布局，不宣称所有历史浏览器脚本在新布局下均重跑通过。本轮采用 `tests/unified_universe_browser.py`、更新的真实上传测试和压缩包测试验收新路径。源码内的正式课程退回重交／完整版本历史仍是独立模块，没有新增为云端已完成能力。
