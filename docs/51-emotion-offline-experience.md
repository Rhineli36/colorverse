## 模式、启动与保存

### 真实云端

主入口 `https://colorverse-dev.2999346.workers.dev/`。现有 Supabase 身份、PostgreSQL、私有 Storage、Cloudflare Worker/Hyperdrive 仍是联网依赖；教师权利必须由后端核对。学生使用真实课堂账号。用户网络能否直连 workers.dev 不在本机代理测试中得到保证。

展示入口 `https://colorverse-dev.2999346.workers.dev/exhibition/` 使用同一离线体验前端，本机状态不与真实云端课堂共享。游客无需先选身份。

### 源码包

Node.js 22.12+、pnpm 11.25.0。运行：

```text
pnpm install --frozen-lockfile
pnpm build:competition
node scripts/static-preview.mjs work/competition-site --open
```

打开固定地址 `http://127.0.0.1:5198`。首次安装依赖需要网络；构建后的离线体验不需要 Supabase 配置。真实云端和本地正式课程服务的启动仍按 README、docs/47 配置，不能把此体验包当成完整正式课程服务。

### 静态备用包与 Windows 便携包

- 静态备用包已含构建产物和全部当前素材，不需 pnpm 安装；需预装 Node.js，双击启动命令或 `node serve.mjs --open`。
- Windows x64 便携包附 node.exe 和许可证，不需另装 Node.js；解压、双击“启动展示.cmd”，服务监听 127.0.0.1:5198 后打开浏览器。它是便携文件夹方案，**尚不是完成签名和安装测试的独立 EXE 安装程序**。后续 EXE 入口沿用本次的默认游客逻辑。
- 启动目录和端口保持一致。不同浏览器/端口属于不同 origin，不共享本机体验；关闭启动窗口停止服务，不会主动清除 IndexedDB。不要直接双击 index.html。
- 离线包与云端班级不互相写入。游客不可创作/评分/留言；离线角色选择没有真实密码，也不提供云端教师凭证。
- 本地正式课程任务发布、退回重交、版本历史仍为独立服务模块，不在这条离线主演示路径冒充完成。

## 图片准备与体积控制

建议成品横向 4:3、1600×1200 WebP；缩略图 560×420。复杂纹理可保留 2000×1500 原版用于归档，运行素材另压缩。目标每张主图约 150–400KB，不以固定质量牺牲辨识度；最终需逐张看图。23 张主图加缩略图约 4–12MB 是预算估计，并非当前实测成品体积。当前四张临时图为 4:3，未强行放大至 1600px。

周末按案例 ID 提交图片并标明来源/授权；转换为对应 `<id>.webp` 和 `<id>-thumb.webp`，在共用内容中标记 ready，更新资源记录，再构建。其余占位期间不会发起缺失图片请求。运行包不装入 PPTX、PSD、原始大图、依赖安装目录和课堂私密数据。本机体验后用户自行导入的原图存浏览器，不会自动增大已交付 ZIP。

当前 ZIP 具体字节数和 SHA256 见 `outputs/competition-delivery/打包校验.json`，体积不含真实课堂数据库/私有原始图片。以最终封包实测为准。
