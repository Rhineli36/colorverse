# 创建模板、星球位置与默认场景

日期：2026-10-15。此记录更新 51 号记录中与模板和展示署名有关的旧状态。

## 本次修改

- 六个创建模板共用 `packages/contracts/src/cloud-planet.ts` 的名称、主色调、氛围、星球寄语和创作起始文字。离线学生首次进入默认带入第一套，点击其他模板立即替换为对应起始文字和外观；仍可编辑。已有星球更换默认外观时保留自己的名称、寄语、作品和位置。
- 云端首次创建增加六个模板入口，展示选中模板的寄语，点击确认创建；随机创建也使用同一套起始内容。后端持久保存模板文字与学习氛围，不只留在界面。
- 大宇宙接入现有 Pixi 拖拽能力。学生只可拖动自己的星球；教师/助教可调整所属班级学生星球；游客和其他同学不能代改。离线位置写入独立 IndexedDB；云端位置写入原有 planet.document.position，使用原有 JSON 数据，无需新建表。
- 新增 `PUT /api/v1/cloud/classes/:classId/planets/:planetId/position`，接受 position 与 revision。复用班级身份检查、目标行锁、revision 防覆盖；位置按完整运行轨道与星球体积约束在已有班级边界内。保留原来的文字、颜色、图片与媒体键。
- 位置保存成功后不重新触发旧的聚焦请求，避免相机又把刚拖动的星球移回画面中心。搜索过滤也复用原来的序号和保存位置，不按搜索结果重新排布。
- 没有上传内部背景时，云端和离线统一复用原来的 `apps/web/public/demo/room-0.png` 至 `room-5.png`，按外观模板选择。上传背景优先显示，滚轮仍只上下浏览。已有空背景星球不需重建。
- 按负责人最新明确要求，展示包恢复五位既有案例作者的真实姓名、学号，包括署名与互动作者；姓名学号显示开关继续保留。没有额外编造作者身份，没有打入课堂账号密码、令牌或云密钥；云端私有媒体映射仍从下载包排除。此项取代上版的“同学 01–05”匿名别名。
- 保持上一版简化后的运行和内部元素界面，没有重新增加繁杂参数或内部星环、轨道图层。

## 实测结果

- `pnpm typecheck`、`pnpm lint`、`pnpm build:competition` 通过。
- `pnpm test`：30 个文件、225 项通过。新增数据库检查覆盖云端模板文字保存、移动权限、过期 revision、边界裁切和图片数据保持。
- Windows Chrome / 本机真实鼠标指针拖拽：位置保存；刷新后恢复；后续修改外观不丢失位置；游客不能拖动保存。
- 六个模板逐个点击：名称和寄语均不同且完整；默认场景图实际解码；已有星球切换默认外观不覆盖自写文字。
- 展示目录实际显示五位作者姓名学号，不再是“同学 01”；显示开关可用。测试仅在独立浏览器会话中创建本机星球，不影响用户自己的本机创作。
- 真实云端独立测试班接口检查：其他同学移动返回 403；自己的位置保存成功，重新登录读回；旧 revision 返回 409；图片引用、文字与颜色保持不变。本次仅给隔离测试星球留下测试位置，没有移动真实课堂学生星球。

本机证据：`outputs/template-drag-verification/result.json`、`cloud-api.json`、`creation-template.png`、`moved-own-planet.png`、`default-room.png`。云端浏览器实测另见同目录 `cloud-browser.json`。
