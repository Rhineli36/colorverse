# 连续拖动与留言区修复

日期：2026-10-16。

用户复现：编辑后回到宇宙能拖动一次，放下后再次拖动提示无权限。

根因：保存位置导致投影素材适配器更换，`SceneCanvas` 按 `assets` 重建 Pixi 渲染器，但拖动权限等 effect 只监听字符串值。自己的星球 ID 没变，因此新渲染器未收到 `movablePlanetIds`。旧的首次拖动验收未覆盖保存后重建再拖动。

修复：场景加载、相机、运行状态、轨迹、聚焦、可移动对象和框选配置都在更换素材适配器后重新应用。未放宽游客或同伴权限，位置仍由原有持久化接口保存。

验证：本机展示页新建自己的星球后，真实指针连续拖动四次，每次放下分别保存四个不同位置；刷新读取最后位置，页面脚本错误为零。记录为 `outputs/repeated-drag/result.json` 与第四次拖动截图。

星球和作品交流均调整为先展示已有回应、再展示输入栏。汇总和历史点赞采用红色实心爱心，操作按钮未点赞时白色空心，点赞后红色实心；离线已点赞状态根据当前体验角色的保存记录恢复。教师与学生体验分别记录自己的点赞，避免互相撤掉对方的记录。

上述修复已发布云端，版本 `52550a90-aec1-48cb-8815-3212f80b6ce0`。色彩的奥秘后续改版作为独立本地修改进行，不将尚未验收的学习页混入此部署。
