## 实现摘要

- 共用 `ColorMystery` 取代嵌套折叠条目的主体，提供紧凑的“色彩知识 / 色彩情感”页签、简短标题和返回入口，复用原品牌导航。
- `KnowledgeVisual` 用 CSS/SVG 呈现七个知识主题，首次默认明度；左侧选择主题，右侧呈现原有观察、理解、实践与补充资料。冷暖使用相同构图，双色面积比较使用同一对颜色；没有添加无效实验滑杆。
- `EmotionAtlas` 复用原 `EmotionCases` 调用接口，展示八色系的全部 23 个案例，数量为 4/2/2/3/4/3/2/3；每组选择被记住。卡片单击更新右侧说明，独立“查看大图”打开原图，支持关闭、Esc 和焦点恢复。
- 缩略图统一比例，`EmotionThumbnailFocus` 为后续正式图像保留按案例 ID 调整焦点的入口；完整图片使用 contain，不改变原构图。缺图和加载失败有回退。
- 来源与署名仍可在“参考资料与创作来源”“案例资料与图像来源”中访问。教学正文、案例 ID、HEX、原图映射未改动；内部编码不再作为主体标题。
- `ColorCardPicker` 中查看资料保持原编辑器挂载。普通返回不应用颜色；主动应用才更新现有主色调与参考案例，保留文字、背景、当前页签及其他参数。游客选择学生身份后继续自己的创建流程；已登录学生只进入自己的星球编辑。
- 会话存储只保存学习页的选中主题/案例，不存放或覆盖星球草稿；读取异常时正常回退。响应式布局在窄屏将详情放在下方，并提供温和定位与清晰键盘焦点。
- 未更换登录、数据库、作业和成长元素的接口；未新增在线图像或 AI 生成请求。

## 实际验证

`pnpm typecheck`、`pnpm lint`、`pnpm build:competition` 通过。`pnpm test`：32 个测试文件、231 项测试全部通过。构建中第三方 Zod 包的注释位置警告未影响结果。

本机 Chrome 的真实页面交互验证，外部网络请求全部阻断，仅允许本地静态资源：

1. 七个知识主题逐项键盘选择，右侧标题和完整原始文案一致，明度为首次默认值。
2. 逐项检查 8 色系、23 个案例的 ID、名称、正式 HEX、观察/场景/建议，不串位；选案例不弹窗。
3. 跨色系返回保留该组上次选择。独立大图支持 Esc 返回，原图按比例完整显示。模拟原图加载失败，展示回退且不破坏阅读状态。
4. 游客选色后选择学生身份，进入自己的创建流程并保留色值。
5. 编辑器中上传真实背景文件、输入未保存名称/寄语、微调 HEX，再往返学习页。普通返回保留全部草稿及当前页签；主动应用仅更新主题色与参考案例。保存并刷新后文字、色值和背景引用仍存在。
6. 1366×768、1920×1080 和 390×844 视口检查；手机详情宽度正常，知识和情感两页无横向溢出。长文自然滚动可见，页面脚本错误为零。
