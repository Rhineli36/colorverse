沿用 T01、T02、T03 任务编号和原有教师发布、信息通知、学生提交接口；不迁移数据库，也不修改已有学生作品。`learning-content.json` 保存用户本轮提供的标题、引导、四步创作步骤、提交内容、灵感入口和范例观察，原有教师评价关注、互评提示等内部字段保留。

`AssignmentCatalog` 直接引用任务数据，去掉按数组下标借用学生作品的图片逻辑。新 `AssignmentBrief` 共用组件用于教师发布预览、学生作业邮件、云端提交提示；离线提交表单也可展开“查看作业要求与范例”。三个入口使用同一份文案与图片，避免后续只改一处。图片按比例展示，失败后可重试。

## 七个即时体验工具

左侧七个主题的图示与选择保持原样，右侧增加同构图“原始配色 / 你的尝试”实时对照、一个滑杆、观察提示和重置按钮。切换主题或色彩知识/色彩情感页签保留各主题在当前页面中的数值；重新打开学习页时恢复默认实验值。工具独立于星球编辑草稿，不自动写入星球主题色。

| 主题 | 可调内容 | 比较中保留的条件 |
| --- | --- | --- |
| 色相 | 圆球色相 0—360° | 圆球明度、彩度及环境与构图 |
| 明度 | 圆球明度 30%—85% | 圆球色相、彩度及环境与构图 |
| 纯度／彩度 | 圆球彩度 0—0.14 | 圆球明度、色相及环境与构图 |
| 冷暖 | 偏蓝—灰调—偏橙的环境方案 | 各区域明度与相同构图 |
| 相近配色 | 相邻色相间距 ±5—35° | 各区域明度、彩度和形状 |
| 对比配色 | 圆球与蓝色环境的色相差 0—180° | 圆球大小、明度、彩度及环境 |
| 色彩面积 | 珊瑚色在双色画面中占比 0—100% | 蓝色与珊瑚色的准确色值 |

颜色由 OKLCH 参数生成，直接更新 SVG 对应区域的填充色。冷暖是两组环境方案经灰调的比较，不模拟物理色温；对比角度描述本工具的色相差，不将任何角度规定为最佳配色。面积工具直接修改矩形宽度，所示百分比即画面实际占比。没有对整幅图片统一降低亮度或使用全图滤镜。

组件为 `KnowledgeExperiment.tsx`，参数计算集中在 `knowledge-experiment-model.ts`；使用本地 CSS/SVG 与浏览器原生滑杆，无新增依赖、联网素材或图片下载。

## 验收结果

- `pnpm typecheck`、`pnpm lint`、`pnpm build:competition` 通过。
- `pnpm test`：33 个文件，235 项测试全部通过。新增检查覆盖明度/彩度/色相独立变化、相近与对比保持明度彩度、冷暖的灰调过渡，以及三张素材尺寸与体积。
- 本机 Chrome 实测七个工具的键盘调整、实际 SVG 颜色或面积变化、原始对照不变、切换主题保留数值和重置。明度另经真实指针拖动验证。
- 390 像素窄屏下工具可用，无横向溢出；作业弹窗图片与内容同样无横向溢出。此项为视口模拟，未用实体手机复测。
- 教师逐份选择三模板，检查完整正文、对应图片、自然尺寸与比例后发布；学生信息中收到三份作业，邮件正文与教师预览一致。点击季节作业的提交按钮进入自己的星球，选中 T03，展开后可再看同一份要求与范例。刷新后发布记录仍保留。
- 模拟作业图片请求失败，显示提示并可重新加载；重试后图片正常解码和显示。
- 再跑原学习页流程：23 个案例、完整文案、独立大图、普通返回与主动应用颜色、未保存的名称/寄语/上传背景均通过；保存刷新保留。页面脚本错误为零。
- 主要浏览流程在外部请求全部阻断的条件下通过，本地资源可用。
