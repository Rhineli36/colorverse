## 本次上线内容

1. 55、56 号记录中的色彩知识／情感改版、23 个案例和三张正式作业范例图全部上线。
2. 七个小工具改为七种独立构图：星环观测站、月夜灯塔、晶石花园、湖畔山谷、林间温室、深海来客、双色艺廊。配色与细节控制仍使用原参数模型；同一工具内两幅图保留相同构图。增加“放大对照”，可在大图中继续调整，Esc 返回后保留数值。SVG 无新增下载素材，支持离线。
3. 作业邮件底部改为左侧返回、右侧提交，增加分隔线与足够间距，手机保持可操作布局。
4. 发布作业新增“＋ 新增作业”：标题、要求、逐行步骤、提交内容、灵感入口、范例观察、示范图片；支持预览、返回编辑、未发布关闭确认。三份已有模板保留。
5. 新作业支持 PNG、JPEG、WebP 图片，最多 8 MB、1600 万像素；云端完整解码并生成最大边 2048 的 WebP，不裁切构图。仅需文字时也可不上传图片。本轮没有加入 PDF、Office 或多附件功能。
6. 自定义任务使用独立稳定编号，教师发布、学生通知、带任务提交、作者说明与规则成长均可识别。重复请求保持幂等，学生和非本班成员不能新增或读取越权图片。

## 保存与兼容

- 新增迁移 `007-custom-assignments.sql`，扩展现有 `learning_task_settings` 的任务编号约束，增加说明与图片引用字段。001—006 未修改，旧作品、旧发布、评价与图片记录保留。迁移通过现有哈希校验、事务和锁机制应用到云端。
- 自定义文本存在 PostgreSQL，图片沿用私有对象存储和认证读取接口；服务端按本班教师身份验证发布，班级最多新增 50 份作业。
- 离线使用原 IndexedDB，新增字段有兼容默认值；示范图片经既有导入流程优化后本机保存。学生退出、刷新与重新登录不构成清空。离线的身份选择不提供真实云端认证。
- 当前没有公开的作业附件 URL，学生看图时通过同源认证接口加载。来源和本机账号凭据不写入公开代码包。
