# 背景星球缩放修复与主宇宙文案

日期：2026-10-16。实现提交 `d3f0ea5`，Cloudflare Worker 版本 `b8f5f0e0-06c0-4272-ab44-0b89fbbbbb92`。

## 原因与调整

旧装饰层仅在 `mode === "overview"` 时挂载；缩放和平移把模式改为 `free`，导致整层图片立即消失。旧位置用屏幕百分比和两个相关的取模序列，容易形成斜向串列。

- 改为始终挂载的世界坐标装饰层，读取渲染器实际相机，同步平移、缩放、聚焦过渡和窗口尺寸变化。
- 28 颗小型装饰星球在 14000 × 8000 的世界范围内固定散布，两两距离至少 1450；大小和外观有变化，降低亮度。放大后视野外的星球自然离开屏幕，返回全景会回到原位置。
- 装饰层不接收鼠标事件，不加入学生星球数据、搜索、数量或作业分发；复用已有六张本地 WebP，不增加图片文件。
- 介绍区按用户给定文案显示：设计色彩 · 云端宇宙／让心绪成为色彩，让想象长成星球。／循着微光，遇见彼此心中的世界。移除介绍区旧数量与双击提示；导航仍可查看星球列表。

## 验证

- 类型检查、lint、课堂和展示构建通过；34 个测试文件、238 项测试通过，包括分布稳定、间距和远端四象限覆盖。
- 本地及云端展示的实际浏览器验证：初始全景、按钮放大/缩小、滚轮缩放、拖动空白处平移、导航聚焦、返回全景、窗口缩小。每步保持同一组 28 个世界坐标；可视星球随视野自然变化，不因模式切换全部移除。相机稳定后装饰层与渲染坐标误差小于 0.1 像素，脚本错误为零。
- 云端健康与认证边界检查通过。本轮没有数据库变更，也没有改动已有学生位置、作品和互动数据。
