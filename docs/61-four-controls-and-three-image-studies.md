## 教学引导

- 每项均有“观察、分析、创作启发”，围绕曲面、阶梯、红衣、窗内外、绿叶瓶身、紫金花鸟和橙帆船具体展开，不再使用原温室、潜艇、艺廊等旧场景说明。
- 相近配色强调色相联系以及深浅、材质的层次；对比配色强调差异与强调色的重复；色彩面积提示主色与点缀色，同时说明目光停留还受冷暖、明暗、鲜艳程度和位置影响。
- 引导允许学生有不同感受，不把某个颜色与某种情绪设为唯一答案。

## 技术与验证

保留前两项浏览器滤镜，饱和度使用 CSS saturate；冷暖用局部 SVG filter 定义的 RGB 平衡矩阵，调整整幅图片，0 为恒等变换，透明度不变。这是画面色彩倾向观察，不是重新布光或精确色温标定。每个图片实例使用独立 filter ID，支持原图与调整图、正文与放大窗口同时显示。

移除已替换的 SVG 场景及不再使用的调色模型。四项滑竿按主题保存当前会话内数值，切到静态项再返回、放大窗口编辑后 Esc 返回均保留；重置恢复原图参数。后三项仅放大图片，无隐藏的调节控件。

类型检查、lint、构建通过；34 个测试文件、239 项测试通过。实际浏览器逐项核对七张图、四项滤镜的实际像素变化、左侧原图不变、中性参数保留原图、切换/放大后的数值保留、静态三项无滑竿及重置、完整图像比例和 390 像素手机布局，脚本错误为零。记录与截图在 `outputs/seven-knowledge-images/`。
