## 必要差异

1. 云端需邮箱密码和有效班级权限；展示版学生/教师入口是本地体验身份。
2. 云端呈现该账号所在真实班级的数据；展示版呈现授权样例及当前浏览器的练习数据，不会自动同步到云端。
3. 云端私有图片、上传、原图下载、并发冲突和权限错误需要联网；展示版资源本地提供，保存至当前浏览器。云端作品撤下/恢复等真实管理操作继续保留。
4. 云端额外保留账户/班级选择、多班级管理、真实网络错误与重试提示。展示版不伪造这些云端服务。
