# 参赛前功能固定与验收

本轮共用在线、离线前端，保留现有界面。正式 EXE 封装在确认本轮稳定版本后进行。

## 功能范围

- 上传外观与内部背景：固定圆形蒙版／16:10 内部区域，拖动、四角等比例缩放、单个复位按钮；点击预览空白隐藏边框。两组构图参数分别保存，兼容旧图片。
- 首次学生身份：学号按文本保存并保留前导零，姓名与作品名称独立；已有完整资料跳过。离线退出保留身份与数据，确认“重新开始”后恢复示例。
- 教师通知：从成功保存的星球、作品派生持久消息，首次星球有稳定通知 ID；已读记录在数据库按教师报名身份保存，读过的未评价作业继续留在待评价列表。
- 生长目录：作者和本班教师显示现有评价摘要；没有评分、只有评语、真实零分正确区分。作品详情沿用现有访问规则。
- 音乐：单个全局播放器，三种原创程序合成曲目；默认暂停，记忆选择，导航和身份切换不叠加。文件和许可随展示版打包。
- 评审账号：独立评审班级，只有教师／学生角色，无系统管理权限；真实课堂和评审上传通过报名、星球、作品关联隔离。

## 入口与必要差异

- 课堂：`https://colorverse.de5.net/`，Workers 地址 `https://colorverse-dev.2999346.workers.dev/`。
- 云端评审：上述域名的 `/review/`。评审账号只报名独立评审班；入口标签不承担权限控制，接口每次重新验证实际班级权限。
- 离线展示：上述域名的 `/exhibition/`，本地稳定静态目录 `work/competition-site`。

- 账号凭据单独保存在忽略目录 `work/评审体验账号_私密.txt`，不提交 Git、不进入静态包。

## 维护者恢复评审数据

需本机数据库及后端配置，不提供公开重置接口。先备份 `work/judges-accounts.json`，停止评审使用时执行：

```powershell
$env:HTTPS_PROXY='http://127.0.0.1:18081'
$env:NODE_USE_ENV_PROXY='1'
$env:COLORVERSE_DB_POOLER_HOST='aws-0-ap-southeast-2.pooler.supabase.com'
node scripts/restore-judges.mjs --restore-judges --proxy
node scripts/judges-demo.mjs --seed
```

恢复脚本核对专用标识、课程、班级名称和全部成员；除初始体验账号外，只接受明确属于专用评审课程的导入学生。归档该评审班，再为初始体验账号建立干净体验班。追加导入学生保留原来的已归档班历史，不自动加入重建班。旧评审作品和评价保留，不删除历史、不修改课堂数据及文件。体验者需重新登录获取新班级。脚本的归档备份保存在 `work/judges-backup-<班级ID>.json`。

## 离线封装准备

`pnpm build:competition` 输出完整静态资源到 `work/competition-site`。保留 `competition/`、`emotion-cases/`、`knowledge-examples/`、`assignments/`、`demo/`、`music/` 及构建 assets 的实际目录；按构建结果整体打包，不手工挑资源。

沿用已有本地 HTTP 启动器，不以 `file://` 直接打开；固定本机端口和浏览器用户数据目录，确保 IndexedDB 体验记录连续。无需 Supabase 或 Cloudflare 密钥。尚未生成最终安装 EXE。

音乐来源和许可见 `apps/web/public/music/LICENSE.md`；生成脚本 `scripts/generate-music.py`，不使用第三方采样，无待补音乐文件。

## 功能冻结与剩余事项

本轮不再扩展功能。最终 EXE 安装包尚未制作，需在目标 Windows 电脑上验证启动器、固定存储目录、关闭后重开和完全断网体验。周末学生测试中发现的问题按影响完整演示的程度修复。

三首音乐素材已齐备并随静态包分发。云端共享学生账号的操作彼此可见；多人同时修改同一作品时沿用现有版本冲突处理，不为每位评委建立独立沙盒。恢复评审数据前需暂停体验并通知使用者重新登录。
