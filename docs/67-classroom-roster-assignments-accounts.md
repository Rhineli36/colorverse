## 已完成模块

### 学生名单

- 教师管理默认打开“学生名单”，另外保留“作业管理”和“星球管理”，顶部按实际班级选择。
- 名单来自有效学生选课/点名册账号，不依赖星球。未登录、未激活和未创建星球的学生都可列出。
- 显示学号、姓名、星球或“尚未创建”、已交/应交、待批改和学生详情入口；统计人数、已创建、尚未创建。
- 姓名/学号搜索，未建星球和有未交作业筛选；侧边详情分别显示登录、激活和建星球状态，并读取各项作业状态、评分和评语。
- 复用 Excel 模板、解析、服务端预览、分批创建与清单下载。学号按文本处理，保留前导零；空值、重号、姓名冲突在确认前展示。
- 重复导入识别已有学生并按现有机制关联班级，不覆盖密码、星球、作品或评价，也不因为名单中缺少某人就删除学生。姓名冲突要求教师核对，系统不猜测覆盖。
- 新版账号清单列明首次登录方式，不再发放旧激活码；已有学生仍保留原密码及激活状态。新版以所选课程作为导入账号范围，同范围内关联班级，不会因另一个课程出现同学号、同姓名就自动合并身份；既有跨课程关联保留。

### 按布置作业查看与批改

- 每次发布创建独立记录，保存当时的作业要求、截止时间及应交学生快照。发布时逐人确认对象；后续新增学生需明确“补发”，不会自动改变历史人数。
- 作业列表和单次作业详情均显示实际应交、已交、未交、待批改、已批改；应交为 0 时不显示无效百分比。
- 提交按“本次作业＋学生”取最近的有效提交统计，重复请求及重复上传都不会增加已交人数。自由创作不计入课程完成率。
- 详情列出所有应交学生；未提交者显示占位和文字状态，不提供虚假作品入口。
- 普通提交可选具体布置的作业；从作业通知进入时自动带入具体发布记录，服务端校验该学生确在本次应交名单中。
- 右侧批改面板保留名单、筛选与列表位置，展示学生身份、真实作品、创作说明、提交时间、评分和评语。支持原图下载及最多六张作品图片切换，保持现有单次总上传限制约 8 MB。
- 评分沿用 0—100；空分数不当作零分，实际零分可保存并显示。仅保存成功后更新统计、列表及学生端；保存失败保留输入，切换/关闭有未保存草稿时确认。
- 支持下一份待批改；窄屏使用覆盖式抽屉，表格独立滚动且保留表头。
- 新版本提交进入“已更新，待复核”，原作品和原评价保留。修改已有作品的创作说明也会保存旧说明快照并触发复核；旧分数不会显示为当前内容的评分。
- 保存评分校验教师打开时的提交内容版本；学生已更新内容时拒绝将原草稿写入新版本，草稿保留供重新核对。
- 教师新提交通知按最近提交定位到相应作业和学生；历史或自由作品通知退回现有星球作品详情；删除/无权访问时显示提示。

### 首次激活、登录、修改与重置密码

- 默认“账号登录”：学号/完整登录账号＋密码；学生另有明显的“首次登录：学号＋姓名”。不提供自由注册界面或注册转接 API。
- 服务端使用点名册核验学号和去除首尾空格后的精确姓名；学号文本保留前导零。跨课堂重号时要求教师提供的完整登录账号，不随机匹配。
- 核验只发放十分钟有效、数据库仅保存散列的密码设置凭据，不返回完整登录会话。
- 设置密码时使用认证服务一次用户更新同时写入密码和权威激活标记，随后完成本地状态登记；操作 ID 用于失败恢复，重试不会覆盖已经设置的个人密码。
- 设置成功后自动以新密码登录并核对班级，进入已有的课堂/建星球流程。已有星球不会重新创建。
- 已激活账号不能再次用学号姓名登录或覆盖密码；退出、更换设备和重复导入均不恢复首次激活状态。
- 账号设置在没有星球时也可打开，姓名/学号只读；修改密码要求当前密码、新密码及确认，密码由 Supabase Auth 保存，不建立明文密码表。
- 本班教师核实后可重置临时密码。2026-10-30起按用户要求固定为 `88888888`（8个8）；登录后必须立即设置不同的个人密码，服务端同时阻止临时密码会话访问普通业务。该操作不会恢复学号姓名激活入口，也不会批量改变现有密码。
- 首次核验和当前密码校验包含持久化失败计数与锁定；普通学生不能读取教师名单、发布作业或重置他人密码。
- 兼容既有个人密码与激活状态，不批量重置旧账号。旧账号若本地激活登记缺失，会参考认证服务的既有激活标记和登录记录作保护性核对。

## 增量数据库迁移和权限

## 使用、维护与仍需人工确认的内容

1. 正式教师在新版入口使用原课堂账号登录，先核对班级并导入/预览名单。尚未创建星球的学生现在可直接查看。
2. 发布作业时选择应交学生和可选截止时间；学生从通知进入，或提交时选择相应作业。自由创作继续单独保留。
3. 旧教学任务和作品完整保留。由于此前没有可靠的“某次布置＋学生”关联，历史作品不会自动计入新版完成率。教师需先明确本次发布范围，再在作业详情确认历史作品关联；可以对新成员明确补发。
4. 历史上没有记录的旧内容版本无法凭空恢复。新功能启用后的内容编辑均保留快照；既有评分及作品原记录仍保留。
5. 同一学号跨不同账号范围出现时，向学生提供导入清单中的完整登录账号。既有姓名冲突先核对，不通过重导表覆盖密码或作品。
6. 本轮没有绑定新课堂自定义域名，也没有替换既有课堂/参赛入口。新版已可从独立 Workers 地址使用；若以后绑定课堂子域名，应只绑定到 `colorverse-classroom-next`，不要改动 `colorverse.de5.net/review/` 的路由。
7. 离线展示与 EXE 本轮保持冻结；本轮新增真实账号功能属于线上课堂，不重新封装参赛程序。没有短信、邮件或额外实时推送功能。

后续维护命令（从仓库根目录运行，使用现有私有环境配置）：

```powershell
pnpm classroom:next migrate
pnpm typecheck
pnpm lint
pnpm test
pnpm classroom:next build
pnpm classroom:next deploy
```

如果当前网络连接数据库需要既有代理，迁移命令使用 `pnpm classroom:next migrate --proxy`，并沿用维护环境的代理和连接池设置。迁移校验 SHA256，重复执行不会清空数据或重复建表。

构建与发布脚本读取忽略于 Git 的现有配置文件，使用 reader/writer Hyperdrive 及服务端 Auth/Storage secret；secret 通过标准输入写入独立 Worker，不放在前端或公开说明中。不要为本轮运行 `cloud:deploy`、Pages 的主分支发布或 `package:desktop`。

需要回退时，只回退独立课堂 Worker 的已发布版本。增量表列可保留，不执行删除表、清库或破坏性降级；原参赛 Worker 不参与回退。
