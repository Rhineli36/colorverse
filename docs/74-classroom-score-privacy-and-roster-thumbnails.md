# 云端课堂：评分可见范围与教师名单缩略图

日期：2026-11-03。范围仅云端课堂 `https://colorverse.de5.net/`，不发布比赛 Worker、不构建 EXE。

## 本轮修改

- 作品详情的当前分数和历史版本分数，仅作者本人、该班级的教师/助教可见。同班其他学生仍可浏览作品与教师评语。
- 服务端 `showcaseReview` 在课堂模式下按已验证的班级角色及作品所属 enrollment 判断权限。未授权读取使用 SQL `NULL::float8`，响应包含 `scoreVisible: false`，不向客户端发送实际分数。当前分数与历史分数统一处理；原有班级访问校验、作品撤下规则和写入权限继续生效。
- 前端根据该权限标记隐藏分数，并将同伴查看时的标题显示为“教师点评”“历史评语”。本人/教师仍可查看实际 0 分，未评分不会显示成 0。
- 教师“学生名单”的星球列复用 `CloudPlanetOrb`，使用现有 gallery 的实际星球 document，保留默认外观、上传图片、裁切位置及光效；未创建者显示虚线占位及“尚未创建”。不增加数据库字段，也不另存缩略图。
- 沿用私有图片鉴权缓存及退出清理。搜索、班级切换、名单详情和原有星球入口保持原流程。
- 不执行迁移，不修改已有学生、作品、评分或密码。

## 验证

- `pnpm typecheck`、`pnpm lint`。
- `pnpm exec vitest run`，包含新增的当前/历史评分权限、同伴不能写入、本人可读 0 分、跨班访问拒绝和旧比赛行为兼容测试。
- `pnpm classroom:next build`：课堂前端生产构建及独立 Worker dry-run。
- `tests/classroom-score-privacy-browser.py`：生产构建 + 隔离 Auth/API，三种角色浏览当前和历史评价，教师/本人查看 95 分及历史 0 分，同伴只读评语；默认/上传缩略图、未创建占位及窄屏检查。测试图片和账号全部是虚拟夹具，不作为实际课堂数据。
- 浏览器证据：`outputs/score-privacy/browser-fixture.json`、`teacher-roster-fixture.png`、`peer-detail-fixture.png`、`owner-detail-fixture.png`、`teacher-detail-fixture.png`。
- 发布后的版本、实际课堂只读核查和隔离结果在本文末尾记录。真实学生账号不用于评分写入或密码重置测试。

## 成长里程碑：仅建议，未实施

建议按独立且有效的作品计数，排除同一作品反复编辑/重复请求。5 件可增加明显但轻量的环绕星带，10 件可增加一颗伴生卫星或更丰富的星带。保留学生自选外观及已有元素；主要成长变化可以静态呈现，首次达成再短暂庆祝，并尊重减少动态效果设置。阈值、计数口径、外观参考和对性能的影响待用户及 ASTRA 意见后确定。
