# 多张作业参考图与立冬装扮绑定

日期：2026-11-04。仅发布云端课堂，比赛 Worker、评审/展示路径和 EXE 保持冻结。

## 本轮功能

- 新增作业支持分次选择、移除最多6张参考图，原文件合计不超过8MB。教师预览、已保存内容、作业通知及学生提交页面复用同一纵向展示组件。
- 私有参考图逐张校验、解码并转为WebP，保存有序文件键；读取按索引鉴权。旧单张图片无需迁移重传，仍通过原文件键读取。未发布参考图仅本班教师/助教可读。
- 绑定正式课堂的 `custom-2be615a9-c7b8-4ca7-9953-382d47cce8fa`，标题「立冬 · 色彩中的季节感知」。班级为 `0e3d5476-a19c-4fa3-bd66-b07b4e0cb17e`。绑定按班级和稳定作业编号，不按标题匹配；同名其他作业不触发。
- 检查时这份作业处于已保存、未发布状态。本轮不代教师发布；教师后续确认发布、学生从相应发布记录提交并获得教师数值评分后生效。
- 仅实际课程发布记录中的应交学生、本人星球的有效提交、对应内容版本的教师数值评分可解锁。零分有效，仅有评语无效、未关联历史/自由作品无效。已取得资格持久保留。
- 解锁后可套用「立冬·霜华初绽」边框及配套霜柿小灯，保存位置、浮动幅度、配色、粒子及浮饰开关。刷新、重新登录、进入实际星球后恢复；可取消边框，不收回解锁资格。
- 未解锁款式继续可试戴，伪造前端解锁或替他人保存会被后端拒绝；并发覆盖使用修订号检查。其他皮肤仍不发放资格，星环解锁尚未配置。

## 数据库和权限

增量迁移 `014-assignment-media-and-skins.sql`：给教学任务增加有序媒体键列，新增班级皮肤绑定、学生资格和星球装扮设置三张私有表。明确撤销 PUBLIC/anon/authenticated 访问；只给既有服务端 writer 角色所需 SELECT、INSERT、UPDATE，绑定表仅给 writer SELECT。保留原 RLS、历史不可变约束与课堂/比赛隔离。

迁移前后对7张既有业务表旧字段进行排序哈希核对，保持一致。绑定脚本核对确切班级、任务ID和标题后仅追加绑定，没有重建/清空表，没有修改真实学生、星球、提交或评分。
