# 线上课堂六款成长装扮解锁

2026-11-04，仅更新云端课堂。比赛/评审/展示部署与 EXE 保持冻结。

## 生效条件与统计口径

| 边框及配套浮饰 | 条件 |
| --- | --- |
| 月辉银饰 | 星球外观和内部背景均有服务端验证成功的上传记录 |
| 日冕鎏金 | 向本班其他成员发出的有效互动达到20次 |
| 蓝宝星穹 | 自己的星球和有效作品合计获赞达到10次 |
| 翡翠秘境 | 提交5份不同课程作业 |
| 琉璃虹窗 | 提交10份不同课程作业 |
| 繁花绘梦 | 向本班其他成员发出的有效互动达到50次 |

互动包括点赞、表情、非空留言，排除自操作、失效账号/跨班目标和已移除作品。点赞/表情按人、目标及类型去重；同一人在同一目标的相同留言去首尾空格后仅计一次。获赞合并星球和作品，按点赞人和目标去重。取消的点赞和删除的留言不再计入当前进度。

课程提交要求真实发布记录、应交名单、本人的有效作品与当前班级相匹配。按不同任务编号计算，同一任务的重复上传、重复发布不累加；自由作品、未可靠关联的历史作品和已移除提交不计。不会猜测历史归属。

上传资格要求真实媒体 ID、私有文件键及有效字节数，选择默认图片不算上传；成功上传后再切回默认图片不会丢失已取得资格。上传条件不要求先交过作业。

## 资格与界面

- 上传、提交和互动成功时，在同一事务内核验并保存资格；获赞同时核验接收方。不存在失败提交产生资格的情况。
- 已有真实数据在学生打开装扮页面时补核验，不要求重新完成。已取得资格永久保留，当前有效计数下降不重新锁定。
- 卡片底部显示条件、实际进度、统计说明和是否已解锁；提供“刷新解锁进度”。刷新不替换当前试戴，也不自动更换已保存装扮。
- 已解锁六款沿用立冬的真实套用/保存/取消及浮饰位置、幅度、配色保存。服务端核验资格与修订号，前端不能自行授予资格或替别人保存。
- 立冬继续使用原指定任务评分条件；星环保持锁定，次数条件不会误发立冬或星环。

## 数据与权限

增量迁移015仅允许无作业凭据的上传/次数资格，并增加达成时证据快照，保留全部原立冬凭据。沿用既有私有表和后端 SELECT/INSERT 权限，没有开放 Supabase Data API、增加公开读写权限或改变 RLS。

发放采用幂等插入和按身份排序的事务锁，避免并发漏计或双向互动的锁顺序冲突。进度与解锁列表仅返回本人；同学、教师浏览星球只读取已保存装扮，不返回学生的私有计数或达成凭据。
