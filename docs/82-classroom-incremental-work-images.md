# 作品图片分次添加（2026-11-14）

范围：只发布独立云端课堂 Worker `colorverse-classroom-next`，不发布比赛、展示及 EXE，不进行数据库迁移。

- 学生新提交、修改未评分作品、教师代交复用 `WorkImagePicker`。
- “添加作品图片 / 继续添加图片”支持每次一张或多张，后选图片追加到列表。每张显示完整比例的缩略图、序号、文件名及移除按钮；移除首图后下一张自然作为主图。
- 选图阶段只在浏览器暂存，最后点提交才上传整份作品，沿用现有多图表单及幂等、权限、评分锁定逻辑。
- 最多6张、合计15 MiB，单张3200万像素、单边8192像素。选择超限或格式不符时不替换原有列表；检查图片期间禁止提交。取消选择不清空已选图片，清空文件控件允许再次选择同一文件。
- 新增图片缩略图按顺序生成到最长320像素，释放位图及对象URL；不改变待提交原图。旧Safari不支持缩放位图时使用图片解码回退。预览生成失败仍保留原图选择，不误报提交成功。
- 新提交窗口统一清空整个图片数组，避免前次附图遗留。

验证：TypeScript、修改文件ESLint、前端构建与Worker dry-run通过；上传、课堂及学生作业相关46项自动检查通过。Python Playwright在390 px与桌面布局走通分次选择三张、移除首图/中间图、超过6张或15 MiB不破坏选择、压缩预览加载、学生修改及教师代交、失败保留与原请求标识重试；检查multipart确实包含保留的两张图片。浏览器接口使用隔离夹具，无真实学生数据写入；未使用实体iPhone设备。

发布后版本与比赛隔离校验记录在 `outputs/gradebook/isolation-after.json`；手机预览截图为 `outputs/student-assignments/incremental-student-mobile.png`（使用测试图片）。
