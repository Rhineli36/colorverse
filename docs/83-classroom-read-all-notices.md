# 消息一键已读（2026-11-16）

仅更新云端课堂。消息窗口顶部新增“全部标为已读”，无未读时禁用。发送期间显示“正在标记…”，保存成功后才清除未读标记；失败可重试，多班级部分成功会保留已成功状态。

批量请求复用 `notification-read`，按班级提交点击当时的消息ID快照，每批最多1000条。后端核对当前登录账号的班级身份及消息可见范围，再使用一条幂等 INSERT 写入原有 `classroom_notice_reads`。不接受指定其他成员、不删除通知、不改变教师待批改状态。保存期间新到的消息继续未读。

无需迁移或新增权限。原逐条已读流程保留，比赛前端不启用批量入口。

验证：57项课堂与管理测试通过，覆盖批量保存、重复ID、重复请求、不可见ID整批拒绝、学生越权拒绝、其他教师已读状态隔离、待评价不变及新消息仍未读。浏览器隔离夹具验证失败不清除角标、重试成功、刷新持久、消息列表与待评价记录保留。TypeScript、ESLint及课堂构建/Worker dry-run通过。未替真实用户点击批量已读，保留现有未读数据供用户自行操作。
